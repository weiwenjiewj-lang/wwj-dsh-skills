## 一、正文字体（附件2 §六.1）

| 对象 | 规格 |
|:---|:---|
| 正文 | **小四号仿宋**，标准字符间距 |
| 数字与英文 | **小四号 Times New Roman** |
| 一二三四级标题 | **自定**（模板明确授权自定，但全书须统一） |

> ⚠ **数字与英文必须单独设 Times New Roman**——这是最常被忽略的一条。
> 中英文混排时若整段用仿宋，数字会变成仿宋体数字，与模板不符。

## 二、版式（附件2 §六.2）

| 对象 | 规格 |
|:---|:---|
| 页眉 | 相应**章节名称**，**五号仿宋** |
| 页脚 | **编制单位名称 + 页码**，**五号仿宋** |

## 三、前置部分

| 部位 | 规格（附件2 原文） |
|:---|:---|
| **幅面** | 标准 **A4**；附图、插图（表）可适当加大（§一） |
| **封面** | **湖蓝色**；正上方标题：第一行（或及第二行）项目名称＝**加粗二号宋体**；末行"水土保持方案报告书"＝**小初号黑体**；正下方居中：建设单位和编制单位全称，下一行编写年月＝**三号宋体**（§二） |
| **扉页** | 版式同封面；在建设单位、编制单位名称处**加盖公章**；多家编制单位分别盖章（§三） |
| **责任页** | 列明编写/校核/审查/核定/批准人员，**须亲笔签名**；报告书名称＝**三号黑体**，其他＝**四号**；其中"批准""核定""审查""校核""项目负责人""编写"用**黑体**，姓名与分工用**宋体**（§四） |
| **目录** | **两级**目录；标题＝**三号黑体**，其他＝**四号仿宋**；标准字符间距和行间距（§五） |

- **左侧胶装**；可在"书脊"印制报告书全称。

## 六、其他标注（附件2 §九）

- 需在封面标注项目编号的：封面**右上角**，**四号（或小四号）宋体**；
- 涉密项目：封面**左上角第一行顶格**标注份号，一般 **6 位三号阿拉伯数字**；
  **第二行顶格**标注密级和保密期限，之间用 **★** 分隔，
  字号**三号**、文字**黑体**、数字 **Times New Roman**。

## 七、表格制作规范

### 7.1 表格的字号与字体

附件2 未对表格内文字单列字号，按以下口径执行（**与正文一致**）：

| 对象 | 规格 |
|:---|:---|
| 表内文字 | **五号或小四号仿宋**（同一表内统一；建议五号以容纳多栏） |
| 表内数字与英文 | **Times New Roman** |
| 表题 | **表X 表名**，置于**表上方居中**，五号黑体（全书统一） |
| 表注 | 置于**表下方**，小五号宋体 |
| 单位 | 在表头标注，如"工程占地（hm²）"；**不在每格重复写单位** |

### 7.2 表格的取材（**字段必须逐字取自 tables.json**）

- 报告书表格字段：`references/tables.json` → `报告书`
- 报告表字段：`references/tables.json` → `report_form`
- **不得增删改字段名**；字段名即栏目名，逐字照抄。

### 7.3 表1 水土保持方案特性表（55 栏，模板硬要求）

- **位置**：综合说明后应附（`tables.json` 原文："综合说明后应附水土保持方案特性表，格式内容要求见表1"）
- **栏数**：**55 栏**，一栏不得少（`check_plan.py` 会核）
- **6 条注**必须原样附于表下：

```
注：1.开工时间为施工准备期开始时间。精确到年月。
2.挖方指项目建设期间所需开挖的土方和石方总量，包括项目建设期间的场地平整、基础开挖、
  隧道开挖、井巷开挖等产生的开挖土石方，不含表土（表土单列）、取土（石、料）、地上建筑
  物拆迁建筑垃圾、不出水面的水下清淤量、不出地面的地下工程量及生产期产生的土石方等；
  项目自身建材利用方指用于项目自身的骨料、浆砌石、机制砂等建筑材料的利用量；弃方指
  项目自身无法利用的土石方；综合利用方指弃方中被社会综合利用的数量。
3.水土保持区划应填写《全国水土保持区划》中的一级区。
4.防治指标应填写设计水平年时的综合指标值。
5.防治措施及数量指建设期各类防治措施的名称和数量，如拦挡、排水措施长度，边坡防护、
  土地整治、植物措施、苫盖措施面积，表土剥离面积与方量等。
6.水土保持投资均指建设期的投资。
```

> **注 2 是"挖方/弃方/综合利用方"的口径定义**——写 2.4 土石方平衡时，
> 这三个量的统计范围必须与之逐字对应（尤其"不含表土（表土单列）"）。
> **注 3 要求区划填一级区**——不得填二级区或三级区。
> **注 4 要求防治指标填设计水平年值**——不是施工期值。
