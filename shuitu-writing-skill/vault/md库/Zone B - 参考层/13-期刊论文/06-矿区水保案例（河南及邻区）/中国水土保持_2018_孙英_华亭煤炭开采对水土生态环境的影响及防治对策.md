# 华亭煤炭开采对水土生态环境的影响及防治对策

孙 英，李爱芳2，杨 发，周成录,赵雪莲，沈利玲

(1.青海生产力促进中心，青海西宁810001;2.华亭县水务局，甘肃华亭744100)

[关键词煤炭开采;水土生态环境;华亭

摘要针对华亭生态环境特点及水、煤资源共存的特定水文地质环境条件，总结了全县煤炭资源大规模开采对水土资源和区域环境所产生的严重影响:破坏森林植被、土地资源，引发地质灾害，造成地表径流发生改变，导致地下水资源破坏和水体污染。对水资源承载能力进行调查和分析，提出了确保华亭煤炭能源在未来可持续的水土资源保护与开发的对策和措施。

华亭煤炭资源得天独厚，素有陇东“煤城瓷镇”之称。甘肃省煤炭预测储量为1428亿t,已探明125亿t,保有资源储量120亿t,煤炭资源集中分布于庆阳、华亭、靖远和窑街等矿区，该区域煤炭储量33.7亿t，占全省已探明煤炭储量的42.4%，拥有地质储量34.8亿t,是全国13个重点产煤基地、西北三大产煤矿区之一，也是甘肃省煤、电、化、运一体化综合产业开发的核心区。华亭县地下近 $1 3 4 ~ \mathrm { k m } ^ { 2 }$ 的面积有煤层分布，遍布全县近2/3的乡(镇)，煤炭资源的开发利用从根本上提升了当地的整体经济水平，然而华亭在享受着煤炭带来的巨大收益的同时，也付出了资源枯竭、水功能区破坏、生态环境恶化的沉重代价。目前，华亭县多年平均水资源总量为1.89亿 $\mathbf { m } ^ { 3 }$ ,其中自产地表水1.649亿$\mathrm { m } ^ { 3 }$ ,主要分布在汭河流域，约占全县水资源总量的69%。全县水资源可利用总量为1.135亿 $\mathbf { m } ^ { 3 }$ ,可利用率为 60%,人均水资源量 $9 7 2 ~ \mathrm { m } ^ { 3 }$ ,为全省的88%、全国的46%。华亭经济发展高度依赖于煤炭资源的采掘，如何在保护生态环境的前提下，实现矿区水资源优化配置和科学合理利用成为一个亟待解决的重要问题[1-3]。

## 1 煤炭资源开发对水土生态的影响

## 1.1 煤炭资源开发对土地资源的破坏

## 1.1.1 破坏森林植被

华亭县总土地面积 $1 \ 1 8 3 \ \mathrm { k m } ^ { 2 }$ ，人均占地0.19$\mathrm { h m } ^ { 2 }$ ,县内耕地总面积2.79万hm²，有水土流失面积$8 6 1 ~ \mathrm { k m } ^ { 2 }$ ，占总面积的72.8%，是黄河上中游地区水土流失严重县之一。全县森林覆盖率仅为36.6%，且土层较薄，土壤类型多样，平均土壤侵蚀模数为5000$\mathrm { t } / \big ( \mathrm { \ k m } ^ { 2 } \cdot \mathrm { a } \big )$ ,部分地区高达 $8 ~ 0 0 0 ~ \mathrm { t } / \big ( \mathrm { \ k m } ^ { 2 } \cdot \mathrm { a } \big )$ 以上,致使境内水土流失强度大，范围广。煤矿区森林植被的破坏极为普遍，多处随意建设矿山工业广场、堆放矸石、开山修路、地面塌陷与乱砍滥伐，致使植被覆盖率急剧下降，尤以乱砍滥伐和人类工程活动破坏面积最大，而这种破坏随着矿区的发展还将持续增加。

## 1.1.2 破坏土地资源

华亭煤矿开采对土地资源的破坏表现在：一是井工开采造成塌陷降低了土地利用率并加剧水土流失和沙漠化;二是露天开采区表土剥离毁坏、压占大量土地；三是煤矿生产固体废弃物压占土地。此外，矿山企业开采造成的酸性废水、尾矿废水、洗煤厂废水、废石堆淋滤溶浸土壤和烟尘的排放等，使矿区及周围农田土壤受到严重污染。华亭县地处六盘山青年褶皱山区及东部黄土高原的过渡地带，梁昴起伏、沟壑纵横、地形复杂。据不完全统计，仅矿区就有各类矿井22对，境内石灰石、陶土、坩泥、石灰石、石英砂等资源也相继开发，形成以煤电产业为龙头，化工、建材、陶瓷、电瓷、机械制造等多业并举的地方工业体系。各类工业广场及配套设施建设占用的土地以及由开采引起的土地塌陷持续急增，导致可耕地面积持续减少。

## 1.1.3 引发地质灾害

华亭位于鄂尔多斯地台西南缘，地质构造包含六盘山坳陷体和鄂尔多斯地台，其上层发育着古生代的寒武、奥陶纪的海相地层。由于加里东运动地壳上升，燕山运动侵蚀、堆积形成了由白垩系、六盘山群沙质泥岩、砂砾岩构成关山主体的中山地形，土层发育薄，厚度0.5\~1.0m，地势高差大，山高坡陡。以下白垩系及新三系砂质泥岩、砂砾岩构成基底的低山丘陵，黄土发育较薄，一般厚度0.5\~20m，植被稀疏，山平地陡，水土流失严重。基于复杂的地质条件，境内煤矿遭受的自然灾害种类也相应较多，在山区、丘陵区，临近沟谷、岸坡的塌陷多诱发崩塌、滑坡、槽状陷坑等灾害；在塌陷发生区域通常会产生连锁危害，如水库渗漏、垮坝引发山洪、泥石流等。

## 1.2 煤炭资源开发对水资源的破坏

## 1.2.1 对地表水的破坏

露天矿坑和井工矿抽排地下水，使矿区地下水位大幅度下降，造成土地贫瘠，植被退化，加之矿区地面塌陷、植被破坏，造成水土流失加剧；采矿引起地面塌陷，或覆岩冒落等，导致地表水下渗量增加，河流流量减少或断流，致使地表径流发生改变。

## 1.2.2 对地下水的破坏

煤、水资源共存于一个地质体中，在天然条件下，各有自身的赋存条件及变化规律。煤炭资源的开发与开采，总伴随着地质环境的破坏与改变，也改变了地下水自然流场和补排、流态、动态及水-岩作用环境，导致水资源破坏和水质污染。煤炭开发对地下水资源的破坏程度及其数量，受自然和人为等多方面因素影响，主要是补给条件、地质构造、水文地质条件、开发深度、开发面积、开发阶段、开发量大小、大气降水等。水环境在不断运动交替中从大气降水、地表径流等得到平衡和补给，然而一旦违背客观规律超强度疏降和破坏，就会引起含水层水位下降并打破水资源原有的平衡状态，致使表土疏松、裸岩面积扩大，地表沉陷并诱发其他地质灾害，从而严重制约矿区的农业生产和经济发展，进而引发一系列生态环境效应。

## 2 煤炭资源可持续开发对策和措施

## 2.1 加大污水整治力度，大力发展循环经济

要保障煤炭资源可持续开发，矿山生态环境的恢复治理至关重要。在工业企业节水方面，水资源是生态环境的核心，坚持循环经济发展模式体现生态化和可持续发展的要求。华亭煤业集团公司建设了处理能力达3.35万t/d的综合污水处理站，华亭城区建有处理能力3.00万t/d的污水处理及循环回用工程，全县还有8个矿井废水处理站、2个生活污水处理厂、9个地埋式污水处理站等环保设施，这些设施的建成应用，提高了矿井废水回用率，城市污水处理总量达7700m³/d,企业污水处理量达 $6 8 0 0 ~ \mathrm { m } ^ { 3 } .$ /d,减少污水排放量6500 m³/d,二次循环利用量 $5 7 8 0 \ \mathrm { m } ^ { 3 } / \mathrm { d }$ ,再生利用率达到了39.9%。截至2016 年底，全县处理污水218万t,分别完成 COD 减排 762 t、氨氮减排 34 t 的任务。全县国内生产总值达43.34亿元，万元国内生产总值用水量 $1 8 . 8 2 ~ \mathrm { m } ^ { 3 }$ ,较2015年下降了7.47%;工业增加值达16.35亿元，万元工业增加值用水量为 $4 9 . 9 0 \mathrm { ~ m ~ } ^ { 3 }$ ,与2015年基本持平。农田灌溉水有效利用系数为0.5，用水效率控制目标均在年计划控制范围之内。在强调水资源节约的前提下，实行“资源-生产(减少污染)-消费-资源再生(废弃物回收再利用)”的物质不断循环流动的过程，是对传统工业化过程资源浪费和环境破坏的跨越。未来需要进一步加大污水治理力度，大力发展循环经济。

## 2.2 保护水源改善水质，科学配置水资源

加强城乡水源地综合保护力度，在牛舌堡、四条岭、车厂沟、上关水库(水源地)等设立警示标志牌，埋设铁丝网(绿焊网)围栏，修建管护房，安装视频监控系统，实行24小时全天候监控，确保城乡居民生活水质安全。控制源头，切断污染路径，减少污染物进入地下水的机会和数量。建立全县地表水、地下水和中天水联合定时监测调度系统，针对性地实施水质水量一体的保护管理，确保水资源的合理开发、利用。加强地下水回灌和人工补给增加水资源，改善生态环境。

## 2.3 建立生态矿区示范基地，推进区域环境整治

实施生态矿区重建和生态功能圈建设、煤矸石堆场复垦、露天采场复垦、矿井水综合利用等多项措施，尝试生态环境脆弱区煤炭资源开发生态地质环境保护的新模式。依据全县煤炭资源开发中生态环境保护的成功经验与教训，统筹规划，制定生态环境脆弱区煤炭资源开发的环境保护规划，利用采空塌陷区建设占地10万m²的人民广场，建成莲花湖3A级旅游景区和双凤山公园、米家沟生态园国家级旅游景区等人文品位颇高的休闲娱乐场所，不断提升和加强采煤塌陷区生态环境变化研究。以培育生态、优化环境、保护资源、实现人与自然和谐相处为目标，建设经济、社会、生态三方协调发展的一批水利风景工程4-』。

## 2.4 强化管理，依法保护水资源

加快“采矿保水”法制建设，依法治水、合理开采。以“保护生态环境就是保护生产力，改善生态环境就是发展生产力”的思想为导向，不断完善水法规体系，加强水行政执法工作，强化水资源的统一管理，规范取水行为，加大对超采地下水、泉域水和污染、破坏水资源的处罚力度，全面加强水资源保护。截至2017年底全县水保方案编报率为93%，水保设施验收率仅为19.60%,水保方案实施率只有57.10%，均有不小的提升空间。坚决贯彻执行水法、环境保护法、水污染防治法、水土保持法等法律法规，做到谁污染、谁治理，谁破坏、谁恢复，使专项资金取之有道，用之有效，复垦受奖，不复垦受罚。建立地下水补偿专项基金，科学划分地下水破坏程度等级，建立地下水破坏评估机构，科学厘定地下水破坏等级序列标准，并以此为依据，由矿山企业缴纳地下水失衡补偿费。强化地下水保护论证管理，地质矿产主管部内应加强“采矿保水”论证管理工作9-1]。

## 2.5 深化体制改革，促进水利投资保障机制

多方办水，做到配水资金多渠道、多层次、多元化。华亭县通过改革水利工程投资体制，探索出水务项目多元化投资的新路子，华亭县国有资产投资经营公司利用王峡口水库现有固定资产，联合华亭发电有限责任公司、甘肃华明电力股份有限责任公司组建了平凉市第一家股份制供水企业；华亭华电供水有限责任公司融资，实施华亭县王峡口水库扩建工程，计划将库容为117万m³、年供水能力仅为230万m³的“死水库”，扩建为库容达750万m³、年供水能力达 920万m³的“活水库”。同样，中煦公司投资建设石堡子水库工程和石堡子河纪家庄段河道治理工程，保证60万t/a煤制甲醇项目的顺利实施。全县形成长期稳定的水利建设和保护资金来源，建立水资源开发利用与水环境保护基金。通过政府补贴、社会集资、金融信贷和资本市场等多种形式筹集建设资金，制定“哺农惠农”政策，安排“以工哺农”资金，加大污水回用处理、地下水回灌等水利基础设施建设，确保全县水利水保工程的建设。

## 2.6 强化落实，确保区域环境质量稳步提升

目前，全县污染物总量指标控制，废气中污染物排放总量为16937 t,其中二氧化硫排放量控制在10894t,氮氧化物排放量控制在6 043 t； 废水中 COD 排放量控制在2660 t,氨氮排放量控制在230 t,主要污染物化学需氧去除量完成140 t,氨氮去除量完成42 t,工业废渣排放总量3万t,综合利用量完成36.48万t,工业“三废”综合利用产值达到610万元，完成了上级下达的各项污染物控制指标。经监测，出境段地面水化学耗氧量为12.9 mg/L，地表水水质达标率为 90.9%，区域环境噪声平均值控制在52.2分贝，交通干线噪声平均值控制在68.5分贝，城镇饮用水源水质达标率为100%,污水集中处理率77%，城区全年空气质量优良以上天数达到330天，区域环境质量稳步提升。

## 3 结语

煤炭是陇东地区最具优势的资源之一，而环境是煤炭产业发展的基础。为了更好地保障矿区经济可持续发展，煤矿开发必须充分考虑水环境容量和水资源长期承载能力，高度重视矿区各类致灾因子的变化及由此产生的环境效应，使矿区发展与矿区生态环境保护和生态重建形成一个完整的科学系统。华亭作为甘肃省现阶段重要战略能源基地之一，决定了煤炭资源大规模开采对华亭县水资源的赋存和循环条件所产生的严重影响。目前，人们关注的重点主要集中在节能减排、煤副产品开发利用、生态修复及其评价等方面[10-12]，而就煤矿开采对水土生态环境的影响及其防治策略方面的研究较少，加强这方面的研究与探讨，对科学合理地利用煤炭资源、构建和谐的开发环境、促进生态文明建设具有十分重要的战略意义。
