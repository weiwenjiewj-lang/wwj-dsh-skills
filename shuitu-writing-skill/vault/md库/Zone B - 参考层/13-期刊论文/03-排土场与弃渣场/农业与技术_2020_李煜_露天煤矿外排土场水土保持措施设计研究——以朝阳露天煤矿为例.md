# 露天煤矿外排土场水土保持措施设计研究以朝阳露天煤矿为例

李 煜

(中煤科工集团沈阳设计研究院有限公司，辽宁沈阳110015)

摘要：文章以宝清县朝阳露天煤矿外排土场为例，在分析外排土场弃渣特点、技术参数的基础上，结合项目区地形地貌等特点，提出外排土场拦挡措施设计、排水措施设计和植被恢复措施设计。完成外排土场综合治理的同时，达到改善周边生态环境的目的。

关键词：露天矿；排土场；水土保持措施

中图分类号：S157.2

文献标识码：A

DOI: 10.19754/j. nyyjs. 20200915023

## 前言

露天煤矿在基础建设期间，需要对采掘区域进行大量的剥离工作，这些剥离的土石方被集中堆存在某一区域，形成规模较大的外排土场。外排土场堆置周期长，对其占地范围内及周边生态环境造成一定影响；同时，在降雨和上游来水等外营力作用下，渣体内部凝聚力、粘聚力等物理参数降低、渣体浸润曲线抬高，导致渣体失稳，将造成严重的水土流失，更有甚者可能诱发滑坡、泥石流等地质灾害。一般在实施过程中，建设单位对其水土流失防治采取的标准低于主体工程，防治措施也相对滞后，且施工、投资、运行管护情况较一般，安全隐患较大。因此，对露天矿外排土的水土保持措施设计可有效防治水土流失，并对其它外排土的水土流失防治工作提供参考。

## 1 项目及项目区概况

宝清县朝阳露天煤矿位于黑龙江省双鸭山市宝清县朝阳乡，地理坐标为 $\mathrm { E } 1 3 2 ^ { \circ } 2 2 ^ { \circ } 3 0 ^ { \prime \prime } \sim 1 3 2 ^ { \circ } 3 9 ^ { \prime } 3 0 ^ { \prime \prime } ;$ N46°11′00″\~46°24′30″。露天煤矿井田北东至南西走向长约为25km，北西至南东倾向宽6km，面积$1 2 2 . 5 0 7 4 \mathrm { k m } ^ { 2 }$ ，开采深度为28\~90m标高。朝阳露天煤矿设计规模 $1 1 . 0 \mathrm { M t } ^ { \cdot \cdot ^ { - 1 } }$ ，初设剥采比 $1 2 . 0 \mathrm { m } ^ { 3 } \cdot \mathrm { t } ^ { - 1 }$ ，达产后年剥离量约为4125万m³，储量备用系数1.1，共探明10号煤层资源储量为87071万t，可采储量83664万t，露天矿设计服务年限为80a。项目区地势总体呈西高东低，南高北低，东南及西南为低山丘陵。项目区属中纬度温带大陆性季风气候，多年平均气温3.7℃，多年平均降水量526.20mm，年平均无霜期145d左右，最大冻土深度2.0m左右，多年平均蒸发量1446.2mm。项目区主要分布有暗棕壤、白浆土和沼泽土3大土类。项目区主要为草甸植被和沼泽植被，林草覆盖率20.7%。

## 2 外排土场的弃渣特点

宝清露天矿外排土场设在矿坑的东北部，毗邻矿坑，基底为第4系，第4系由松散粗砂、中砂、细砂、粉砂、粘土组成。露天矿外排土场排弃土方多采用重型运输机械，平台经反复碾压，土壤的密实度增大，入渗慢，产流量较大。边坡随排土量的增加而逐渐形成，多为机械整平，碾压次数少，结构松散，受降雨影响容易产生水土流失。

## 3 外排土场技术参数

## 3.1 堆置方案

外排土场占地面积为 $1 2 0 . 4 4 \mathrm { h m } ^ { 2 }$ ，最终排弃总量4300万m³，外排土总容量为4838万m³。外排土场堆置采用分层排弃法，每15m布设1处平台，排土台阶7个(地表标高78\~180m)。剥离物采用汽车—推土机排土工艺，即采用汽车将剥离物运至外排土场倾倒，由推土机辅助推平。汽车排土平盘做成4%的反坡，坡顶处由推土机推成高度不低于车轮直径2/5的挡车土堤，汽车排土时靠近台阶坡顶线卸载，大部分物料可自行滑落，残留部分由推土机推下。外排土场主要技术参数见表1。

## 3.2 外排土场级别

依据《水土保持工程设计规范》（GB51015-2014)，弃渣场水土保持防护工程主要依据堆渣规模、渣场所处位置及失事后对工程和环境的危害程度等进行设计，将渣场划分等级，本工程外排土场最终堆渣量4300万m³>2000万m³，堆渣高度102m>100m。按堆渣量、堆渣最大高度、弃渣场失事对主体工程或环境造成的危害程度确定的弃渣场级别不一致时，按高级别执行。确定外排土场级别为1级。

## 4 外排土场水土保持措施设计

## 4.1 透水石堤

按照水土保持工程防治原则，采取先拦后弃原则。根据现场调查，当地冬季寒冷，冻深大，刚性砌体易发生冻胀破坏，透水石堤具有抗冻胀能力好的优点。同时当地可施工时间较短，透水石堤施工难度小，施工简便。

设计透水石堤断面型式采用梯形，断面尺寸采用550cm（下宽)×100cm（上宽)×150cm（高)，内外坡比均为1:1.5，透水石堤长3573m。根据现场调查，透水石堤基础有淤积土，采用15cm砂砾石换填。透水体围排土场坡底脚外一周，紧邻坡脚，反滤料一侧回填，另一侧排水沟种草，堤身填筑材料压实后相对密度不小于0.60。

## 4.2 平台排水沟

外排土场的剥离土料经重型机械层层碾压后，密实度加大，不利于雨水的入渗，加之平台及边坡坡面集水面积较大，当出现短历时高强度的暴雨时，由于入渗少产流多，有可能产生集中径流冲刷平台，为及时排出平台产生的径流，确保外排土场平台及边坡稳定安全，在外排土场各平台布设排水沟，采用明沟排水的方式。平台排水沟采用UD40预制矩形槽，断面尺寸采用40cm（底宽)×40cm（顶宽)×40cm(高)，壁厚10cm，底板厚度10cm，矩形槽材质为预制钢筋混凝土。平台排水沟坡降为 $i = 1 \% o \sim 5 \% o$ ，土方回填压实度应大于0.6，设计平台排水沟总长度7159m。

## 4.3 边坡排水沟

排土场边坡设置纵向排水沟，将上游斜坡及平台汇流引入下游沟道。边坡排水沟采用UD40预制矩形槽，断面尺寸采用40cm（底宽)×40cm（顶宽)×40cm（高），壁厚10cm，底板厚度10cm，矩形槽材质为预制钢筋混凝土。排水沟坡降为i=0.543，土方回填压实度应大于0.6，共设计6条边坡排水沟，设计排水沟总长度312m。

## 4.4 植物措施设计

在外排土场达到设计高度时，对外排土场的平台、边坡进行削坡开级、覆土、平整后，在平台面营造灌草相结合的恢复林带，在边坡上撒播草种恢复植被，栽植沙棘10万株，撒播草籽面积 $3 1 . 6 8 \mathrm { h m } ^ { 2 }$ 。沙棘冠丛高30cm，株行距为1.0m×1.0m，栽植前平台采用穴状整地，整地规格为 $3 0 \mathrm { c m } { \times } 3 0 \mathrm { c m } { \times } 3 0 \mathrm { c m }$ 。草种可选用早熟禾、芨芨草等，播种量 $2 5 0 \mathrm { k g } \cdot \mathrm { h m } ^ { - 2 }$

## 5 结语

外排土场的水土保持工程措施主要为透水石堤、预制混凝土平台排水沟和边坡排水沟及绿化措施。排土场采取水土保持措施以后，不仅可有效减轻水土流失，而且有利于排土场边坡的稳定，有效改善了周

边的生态环境。
