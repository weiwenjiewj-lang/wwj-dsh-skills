# 露天煤矿外排土场选址及水土保持措施设计

——以吐鲁东露天煤矿为例

陆可生，辛伟

(甘肃四创水利工程咨询有限公司，甘肃兰州730000)

[关键词]外排土场；选址；水土保持；露天煤矿

[摘要]外排土场是露天煤矿项目水土流失重点防治区域，既要考虑自身安全，又要考虑水土流失防治，其合理选址及水土保持措施设计全面、合理可行尤为重要。以吐鲁东露天煤矿为例，结合外排土场自身特点，对选址合理性进行分析评价，从全方位水土流失防治方面进行水土保持防治措施典型设计。选址合理性主要从外排土场对周边重要基础设施的影响、用地预审与选址意见书前期相关手续办理和边坡稳定等方面进行分析；水土保持措施设计结合吐鲁东露天煤矿外排土场所处北方风沙区的特点，从“挡”“排”“护”“整”“临”5个方面进行设计，减少生产建设过程中的人为水土流失。

## 1 研究区概况

吐鲁东露天煤矿位于玉门市西北150 km处的酒泉北山区，行政区划隶属于酒泉市肃北蒙古族自治县马鬃山镇，为新建项目，主要由采掘场、工业场地(含选煤厂）、场外道路、外排土场、供电和供水工程等组成。井田面积 $2 4 . 5 9 ~ \mathrm { k m } ^ { 2 }$ ,露天开采场地表境界面积9.18$\mathrm { k m } ^ { 2 }$ ,生产规模230万 $\nu \mathbf { a }$ ，属中型露天煤矿，平均剥采比 $1 9 . 2 1 \ \mathrm { m } ^ { 3 } / \mathrm { t }$ ，服务年限为21.7a。据勘探资料显示，露天开采境界内的地质资源量为6 610.60万t,可采原煤量5990.93万t,设计可采储量5562.17万t,最大开采深度为290 m。

矿区地处戈壁荒滩，区内地势东、南高，西、北较低，最高海拔1970m，最低海拔1906m。气候类型属中温带大陆性干旱气候，多年平均降水量72.1mm，多年平均气温为4.5℃，极端最高气温35.4℃，极端最低气温-37.1°C,年平均蒸发量3040mm，最大冻土深度130 cm，多年平均风速 $4 . 6 \mathrm { ~ m } / \mathrm { s } _ { \mathrm { ~ o ~ } }$ 土壤类型为灰棕漠土。植被类型属荒漠草原植被，植被覆盖率3.0%。矿区在全国水土保持区划中的一级分区为北方风沙区，容许土壤流失量为 $2 ~ 0 0 0 ~ { \mathrm { \ t / ( \ k m ^ { 2 } \cdot { \mathrm a } ) } }$ ,土壤侵蚀类型为风力侵蚀，原地貌土壤侵蚀模数 $3 5 0 0 \ : V ( \mathrm { k m } ^ { 2 } \cdot \mathrm { a } )$ 侵蚀强度为中度。

## 2 项目概况

## 2.1 项目区概况

外排土场位于采掘场的东边，牛圈子冲沟的南侧，工业场地（含选煤厂）的北侧。总规划面积198.00$\mathrm { h m } ^ { 2 }$ ,汇水面积为 $0 . 3 0 \mathrm { k m } ^ { 2 }$ ,容量14000.00万 $\mathbf { m } ^ { 3 }$ ,累计排弃10 591.03万 $\mathbf { m } ^ { 3 }$ ,起始排土高度1920 m，最终排弃标高2010m,堆高90m，台阶高度20m,分5个台阶。至设计水平年(达产第1年)结束，外排土场扰动面积为 $1 0 1 . 2 6 ~ \mathrm { h m } ^ { 2 }$ ,设计排土3479.60万 $\mathbf { m } ^ { 3 }$ ，土石方调配利用后最终排土3470.56万 $\mathbf { m } ^ { 3 }$ 。设计水平年外排土场起始排土高度1920m，最终排弃标高1961 m，台阶高20m，分3阶，坡面角30°。主体设计考虑了与牛圈子冲沟及工业场地(含选煤厂)的安全距离，相较于采掘场及周边地形，该处位置较高，不存在洪水威胁。外排土场地处戈壁荒滩，地形较平缓，降雨入渗快，基本不产生径流。

## 2.2 堆置方案

外排土场堆填作业按照“从下至上、逐层碾压”原则进行，堆渣方式采用分层平起后退法，作业面开拓采用填筑单元升层法。外排土场边坡按照台阶坡面角30°堆放，碾压密实度为0.93，按照分区分块原则进行水平方向开拓，各区块间相互交错衔接，堆渣台阶高度20 m[1]。

## 2.3 排土工艺

根据卡车排土工艺，采用边缘排弃方式，自卸卡车在排土工作线上卸载后，大部分排弃物自溜至坡下，少量遗留在坡顶的排弃物用推土机推至坡下。本着由近及远的排弃原则进行建设，外排土场建设初期，初始排土台阶以分层排弃的方式逐渐增高，直至达到一个标准排土台阶高度，并由该水平面扩展，直到排弃至外排土场最终规划用地红线范围处为止。主要技术参数见表1。

## 2.4 排土计划

外排土场排弃时间为建设期至达产第6年，堆高90m，达产第7年实现内排，二采区往首采区排弃剥离物，三采区往二采区排弃剥离物，以此类推，直至排弃完毕。生产期严格按照矿山地质环境保护与土地复垦方案，完成相关治理与恢复[2]。

## 2.5 外排土场级别

依据《水土保持工程设计规范》（GB51018—2014)(以下简称《规范》），弃渣场水土保持防护工程主要依据堆渣规模、渣场所处位置及失事后对工程和环境的危害程度等进行设计，将渣场划分等级。本工程外排土场建设期最终堆渣量3470.56万m³，堆渣高度41m。按堆渣量、堆渣最大高度、弃渣场失事对主体工程或环境造成的危害程度确定的弃渣场级别不一致时，按高级别执行，最终确定外排土场级别为1级[1]。

## 3 外排土场分析

## 3.1 水土流失成因

露天煤矿开发建设引起和加剧原地貌水土流失的因素主要包括自然和人为因素。自然因素是潜在的，人为因素是造成土壤侵蚀加速发展的主导因素，主要表现在以下3个方面：一是扰动和破坏天然耐旱植被，使地表形成裸露面；二是使表层土壤松散性加大，固结性降低，导致土壤的抗侵蚀能力降低；三是人为改变了原地貌形态，形成人工再塑地貌，加大了地面坡度，使得土壤侵蚀加剧[1-2]。

## 3.2 合理性分析

## 3.2.1 选址合理性分析

外排土场范围区域地质构造简单，不存在断裂构造、滑坡、崩塌、泥石流、塌陷等不良地质问题，场地地基土层及地形条件较好，区域稳定性好。下垫面为戈壁荒滩，地形较平缓，降雨入渗快，基本不产生径流，且地势较高，无洪水威胁。周边无风景名胜区、自然保护区，不在林业保护区。设计水平年用地范围距离采掘场、工业场地(含选煤厂)的距离均大于安全防护距离，满足要求。同时，据《肃北蒙古族自治县德丰矿业有限责任公司吐鲁东露天煤矿地质灾害危险性评估报告》关于外排土场的分析结论，排土场东部存在小范围汇水，通过在排土场东部设置截水沟等排水措施，将汇水疏排至牛圈子沟，再向东排出区外。外排土场距露天采坑地表境界线最近距离200m，距南部工业场地230m，虽在极端气候或冻融条件下，外排土场底部可能发生底鼓，给外排土场周边小范围区域的稳定造成影响，但经综合分析不存在外排土场溃坝和对采坑及工业生产区造成危害的可能。从水土保持角度分析，该外排土场选址可行[1]。

## 3.2.2 前期相关手续办理情况

本工程已取得用地预审与选址意见书，外排土场为该文件确定的位置，手续合规。根据水保监〔2020]63号文要求，取得了外排土场所在地自然资源、生态环境等部门同意的选址意见单。从水土保持角度分析，该外排土场前期相关手续齐全。

## 3.3 稳定性分析

主体设计对外排土场的边坡进行了稳定性分析，结果如下：天然工况下外排土场边坡高度90m、最终边坡角为20°，边坡稳定性系数为 $1 . 2 3 3 > 1 . 2 _ { \scriptscriptstyle ( }$ 暴雨工况下由于排弃渣石属大孔隙散体结构，因此长时间极端暴雨时会在坡体内形成渗流。经计算，当外排土场边坡高度90m、最终边坡角为20°时，暴雨工况下外排土场边坡稳定性系数为 $1 . 0 8 2 > 1 . 0 5$ ,边坡处于基本稳定状态，符合《规范》要求。地震工况下当外排土场边坡高度90m、最终边坡角为20°时，外排土场边坡稳定性系数为1.103>1.05,边坡处于基本稳定状态，符合《规范》要求[2]。

## 4 外排土场水土保持措施布局与设计

## 4.1 外排土场水土保持措施布局

施工前期主体设计明确了外排土场坡脚挡渣墙、土质排水沟措施，方案新增外排土场东侧、每级台阶处修筑土质拦水埂措施，并在主体设计土质排水沟末端顺接土质沉沙池。施工过程中方案新增防尘网苫盖措施。施工结束后方案新增外排土场边坡及顶部平整措施，配合降尘洒水促进土壤结皮，并在外排土场边坡整治区域进行碎石压盖，碎石来源于采掘场剥离[2-4]。

## 4.2 外排土场水土保持措施设计

## 4.2.1 工程措施

## 4.2.1.1 设计原则与标准

工程措施设计原则为：①主体设计中具有水土保持功能的措施设计标准高于水土保持设计要求的，采用主体设计标准；②遵循经济和操作性强的原则，既做到控制投资、便于施工，又要控制水土流失。

工程措施设计标准：①排水工程设计标准。根据《规范》规定，“弃渣场永久性截排水措施的排水设计标准采用3\~5a一遇5\~10min短历时设计暴雨”。主体工程中土质排水沟设计标准采用 50 a 一遇10 min暴雨标准。依据工程措施设计原则“主体设计中具有水土保持功能的措施设计标准高于水土保持设计要求的，采用主体设计标准”，经确定，土质排水沟设计标准采用50a一遇10min暴雨。②挡渣墙设计标准。建设期外排土场堆渣量3470.56万m³，最大堆渣高度41m，失事对主体工程或环境造成的危害较轻。根据《规范》设计标准，外排土场级别为1级，主体设计的挡渣墙对应等级为2级。

## 4.2.1.2 具体措施

1)挡渣墙。①施工前期在外排土场边坡坡脚设置挡渣墙1660.00m。挡渣墙采用M10浆砌石砌筑并勾缝，基础用换填30 cm厚三七灰土夯实，坡面坡比为1:0.3,基础埋深1.5m,地面高度1.5m,地面以上0.5m处以3.0m间距设置排水孔。②稳定性复核。经查主体设计报告，外排土场基底土层容重取16.5$\mathbf k \mathbf N / \mathbf m ^ { 3 }$ ,内摩擦角取25°，黏聚力取 $1 0 \ \mathrm { k P a _ { c } }$ 排弃渣石容重取 18. $5 ~ \mathrm { k N } / \mathrm { m } ^ { 3 }$ ，黏聚力取 15 kPa,内摩擦角取28°。采用理正软件对库伦土压力、抗滑系数、抗倾覆系数以及地基应力进行计算，稳定性符合《规范》挡渣墙设计要求。

2)土质拦水埂。施工前期在外排土场东侧修筑土质拦水埂1310.00m，以拦截坡面产生的汇水。同时在外排土场每一级台阶处修筑土质拦水埂，避免雨水冲刷坡面形成侵蚀冲沟，台阶处修筑土质拦水埂8294.00 m。拦水埂顶宽0.5m、底宽2.0m、高0.5m、坡比1：1,共计修筑土质拦水埂9604.00m。

3)土质排水沟。施工前期在外排土场南侧、西侧重点地段坡脚处修筑顶宽2.0m、底宽1.0 m、深0.5m、坡比1：1的土质排水沟，排水沟采用就地开挖的土质渠，并压实，压实系数不小于0.90，排水沟长

1660.00m。①安全性、满足性复核。洪水标准主体设计按50 a一遇10 min最大暴雨。②降雨强度。主体设计采用50a一遇降水量43.63mm/h。③清水洪峰流量计算。根据《规范》，对汇水面积的洪峰流量及洪水量加以计算。外排土场最大汇水面积为0.30$\mathrm { k m } ^ { 2 }$ ,经计算，外排土场50 a 一遇10 min洪峰流量 $Q _ { \sharp \sharp }$ 为1. $4 6 \mathrm { ~ m } ^ { 3 } / \mathrm { s } _ { \mathrm { ~ o ~ } }$ ④断面复核。采用明渠均匀流公式进行校核，土质排水沟最大过水量为 $1 . 9 9 ~ \mathrm { m } ^ { 3 } / \mathrm { s } _ { \circ }$ ⑤洪水校核。采用扩大20%的洪峰流量进行验算，经计算，土质排水沟设计过水流量大于扩大20%的洪峰流量$( 1 . 7 5 ~ \mathrm { m } ^ { 3 } / \mathrm { s } )$ ，满足排放要求。

4)土质沉沙池。在土质排水沟末端修建1座土质沉沙池，内衬土工膜，沉沙池尺寸为宽6.0m、长12.0m、深2.0m、坡比 $1 : 1 _ { \mathrm { ~ o ~ } }$ 按照水流在沉沙池沉淀1 min计算，沉沙池容量满足沉淀容量要求。每座沉沙池土方开挖量为 $4 8 . 0 0 \mathrm { ~ m ~ } ^ { 3 }$ ,衬土工膜479.29 m²。

5)土地整治。土地整治是对因生产、开发和建设损毁的土地进行整治、改造、修复，使之达到可开发利用状态的水土保持措施。工业场地区土地整治分粗整和细整两步进行。粗整时先按照路基周边的地形、地势特点及填高要求，确定需要回填的重点部位，然后利用推土机等施工机械将土方推运至坑洼地填方区域：进行坑洼回填时，对坑洼地一般采用条带式分条填埋，或任意工作线(面)回填，然后碾压平整；回填结束后力争坑平渣尽。粗整结束后，对机械整治后遗留的小型坑洼地，采用人工方式，利用铁锨等工具进行铲平、填埋处理，最终达到整治设计要求。施工后期在外排土场边坡及顶部进行平整，设计土地整治93.16 hm²，采用74kW推土机机械整治。

6)碎石压盖。施工后期方案新增外排土场边坡土地平整区域进行碎石压盖，碎石来源于采掘场剥离，铺设在外排土场边坡以抵抗风蚀，补充碎石压盖30.20$\mathrm { h m } ^ { 2 }$ ,厚度10 cm,共用碎石3.02万m³。
