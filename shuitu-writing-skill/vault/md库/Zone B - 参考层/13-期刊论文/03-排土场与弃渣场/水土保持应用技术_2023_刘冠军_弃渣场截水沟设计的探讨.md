# 弃渣场截水沟设计的探讨

刘冠军

(辽宁省水利水电勘测设计研究院有限责任公司,辽宁沈阳110006)

中图分类号:S157 文献标志码:A doi:10.3969/j. issn.1673-5366.2023.04.09

摘要:弃渣场截排水工程是其防护措施体系的重要组成部分，截水沟设计的合理性对弃渣场的安全稳定具有举足轻重的影响。由于弃渣场占地较小，多无实测水文资料，截水沟设计洪峰流量普遍采用中国水利水电科学研究院水文研究所推理公式进行计算。在实际工作中，各省(自治区、直辖市)根据各区域特点，在中国水利水电科学研究院水文研究所推理公式的基础上进行了深入研究，并制定了符合区域特点的计算方法。以朝阳县东大屯乡弃渣场截水沟设计为例，根据《辽宁省中小河流(无资料地区)设计暴雨洪水计算方法》，推求截水沟洪峰流量，作为截水沟设计的依据，以供大家学习探讨。

关键词:弃渣场;截水沟；洪峰流量;措施设计

## 1 项目情况

弃渣场位于朝阳市朝阳县东大屯乡，等级为4级，为沟道型弃渣场。根据中华人民共和国国家标准水土保持工程设计规范(GB21018—2014)，截水沟设

一是以市级单元划定漏斗范围时，由于等水位线跨区，无法判断等水位线是否封闭，难以确定漏斗范围；二是单井开采的情况下，局部也会形成水位下降区，因此多大面积的水位下降区才能算漏斗，难以分辨。

## 3 结论及建议

通过以上综合分析可知，总体来说这两种方法是利用当期的等水位线划定的漏斗范围。优缺点分析:第一种漏斗划定方法，优点：精度高、范围准、实用性强。缺点:划定范围人为因素影响大。能够客观地显示漏斗的影响范围，一定程度上反映漏斗的发展变化。但是圈定方法受人为因素影响较大，不同的地质工作者绘制的漏斗范围可能差异较大。第二种漏斗划定方法，优点：操作简单，好绘制，效率高。缺点：精度低，实用性弱。利用封闭等水位线圈定，方法简单，受人为因素影响较小，但是横向发展的漏斗，可能无法圈定封闭等水位线，画不出漏斗范围，实用性不强。此外，对于市级范围由于等水位线跨区，难以分析等水位线是否封闭，无法判断是否为漏斗区。

建议根据实际工作需求选择漏斗划定方法。当进行大区域划定地下水漏斗、且精度要求不高时，可计洪水标准为20a一遇。弃渣分台阶堆放，台阶边坡1:2,渣面最高点高程为191.5m,渣面坡率为1:0.005，弃渣结束后渣场表面采取植草绿化。为防止弃渣场上游坡面汇水对弃渣场的冲刷，在弃渣场占地边界修建浆砌石截水沟。

采用第二种漏斗划定方法，效率高。当在小范围且精度要求高的地区进行地下水漏斗划定时建议采用第一种方法。

## 3.2 主要设计要求

断面形状:土质坡面截水沟断面宜采用梯形，岩质坡面截水沟断面可采用梯形或矩形。

断面设计:设计断面的底宽和深度应适应机械开挖的最小尺寸要求，人工开挖断面不受此限制。土质截水沟内坡应保持自然稳定，边坡比一般大于1：1.0，用砖石或混凝土铺砌的截水沟内坡应按最优水力断面设计。截水沟的最小纵坡应满足不淤积要求。

流速:截水沟的最小允许流速为0.4m/s。截水沟水深0.4\~1.0m时，其最大允许流速按“明渠最大允许流速表”选用，在此水深范围外查“最大允许流速的水深修正系数表”进行修正。在陡坡或深沟地段的截水沟，宜设置跌水构筑物或急流槽，急流槽可采用矩形断面形式，槽深不应小于0.2m，槽底宽度不应小于0.25m。

安全超高：安全超高不得小于0.2m。

弯曲半径:截水沟转弯处，其中心线的弯曲半径可采用不小于设计水面宽度的2.5倍。

防冲要求：截水沟出口衔接处，应铺草皮、抛石或作石料衬砌防冲。

## 3.3 断面设计

初拟截水沟断面尺寸底宽0.6m,沟深0.85m(含0.2m安全超高)，边坡系数1.0,浆砌石粗糙系数取0.025,纵坡比降为0.065,计算该设计断面过水流量为 $3 . 9 7 ~ \mathrm { m } ^ { 3 } / \mathrm { s }$ ,流速为4.89m/s,过水流量略大于设计流量，流速满足浆砌石截水沟不冲不淤流速范围，满足设计要求。故初拟断面合理。

## 4 施工方法

底宽≤0.5m的截水沟采用人工开挖施工，底宽>0.5m的截水沟采用机械开挖，人工辅助修整。浆砌石采用坐浆法分层砌筑，上下层砌石错缝砌筑，外露面平整美观。砂浆填充饱满，砌缝采用扁铁插捣密实，缝隙较大时充填片石。水泥砂浆养护时间不低于14 d,浆砌石排水沟石料饱和抗压强度>40MPa,单边最小尺寸 $\geqslant 2 0 0 \ \mathrm { ~ m m }$ 。沟底砂砾垫层摊铺厚度约15\~25cm，并进行平整压实。为防止冻胀，一般每隔5m设一道伸缩缝，缝宽2cm，缝内填沥青麻丝。
