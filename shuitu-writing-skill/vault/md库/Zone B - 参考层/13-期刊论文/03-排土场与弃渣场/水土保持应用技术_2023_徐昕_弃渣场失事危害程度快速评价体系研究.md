# 弃渣场失事危害程度快速评价体系研究

徐昕 刘昱 孙丹丹2 李杰 陈芳

(1. 湖北省水利水电规划勘测设计院，湖北武汉430070;2. 湖北正平水利水电工程质量检测有限公司，湖北武汉430064)

中图分类号:S157 文献标志码:A doi:10.3969/j. issn.1673-5366.2023.04.11

摘要:鉴于弃渣场级别确立过程中弃渣场失事的危害程度受众多因素影响难以权衡，以弃渣场特征准则、弃渣场性质准则和弃渣场防护措施准则3个方面构建弃渣场失事危害程度快速评价模型，并尝试性地确立了各项评价指标的阈值。采用湖北省鄂北地区水资源配置工程作为熵权法的大数据进行权重拟合，并引用拉格朗日组合模型对层次分析法和熵权法两类权重进行组合，以克服主观和客观权重的非一致性问题。将评价模型运用到湖北省某高速公路工程弃渣场失事危害程度的研究中，分析结果与实际情况较为吻合，为弃渣场的前期快速设计提供了一类新的方法。

关键词：监测；信息化；高分辨率对地观测系统

## 1 研究背景

生产建设项目在进行水土保持设计过程中，弃渣场级别的选择是水土保持设计的关键《水土保持工程设计规范》GB51018—2014)规定弃渣场等级根据堆渣量、最大堆渣高度、渣场失事对主体工程或环境的危害程度确定弃渣场级别，在级别不一致时，就高不就低。在实际的设计过程中，堆渣量、堆渣最大高度均为量化指标容易确定，但渣场失事对主体工程或环境造成危害程度则较为模糊。失事危害程度与弃渣场类型，距离重要设施距离，堆渣量，堆高，汇水面积，排水措施等因素息息相关，弃渣场失事危害程度是弃渣场一段时期的特征，随着弃渣场实际施工过程的推进，失事危害程度也是一个动态变化的过程，因此对弃渣场失事危害程度的评估是必要的。弃渣场的失事危害程度是多因素决策的科学系统，由于影响因子的多重性，当前对弃渣场失事危害程度的评价研究甚少，韦立伟等提出了新建重庆至万州铁路的弃渣场潜在危险性评价模型，并通过实例验证，取得了较好的一致性，但鉴于不同的地域特点，弃渣场的失事危害程度评价标准尚不统一，本文尝试性地构建了弃渣场失事危害程度的评价体系，通过拉格朗日组合模型确立权重，以实现弃渣场失事危害程度的日速评价，保证弃渣场的快速设计。

渣场失事危害程度快速评价体系，体系主要有3个层次组成:目标层、准则层和指标层，其中目标层为弃渣场失事危害程度快速评价体系 $\operatorname { A } ;$ 准则层主要为生产建设项目弃渣场失事危害程度的3个评价准则，主要为弃渣场特征准则 $\mathbf { A } _ { 1 }$ 、弃渣场性质准则 $\mathbf { A } _ { 2 }$ 和弃渣场防护措施准则 $\mathrm { A } _ { 3 }$ 3，指标层主要为各准则层对应的评价指标，其中弃渣场特征准则层 $\mathrm { A } _ { 1 }$ 对应的下一级评价指标有：渣体边坡坡度 $\mathrm { A } _ { 1 1 }$ 、最大堆高$\mathbf { A } _ { 1 2 }$ 、汇水面积 $\mathrm { A } _ { 1 3 }$ 和弃渣量 $\mathrm { A } _ { 1 4 } \mathbf { \dot { \Omega } } ^ { \bullet }$ 弃渣场性质准则层$\mathbf { A } _ { 2 }$ 对应的下一级评价指标有：弃渣场类型 $\mathbf { A } _ { 2 1 }$ 、渣体性质 $\mathbf { A } _ { 2 2 }$ 和距离重要设施距离 $\mathrm { A } _ { 2 3 } ;$ 弃渣场防护措施准则A₃对应的下一级评价指标有：压实度 $\mathbf { A } _ { 3 1 }$ 、截排水措施 $\mathbf { A } _ { 3 2 }$ 和分级堆置措施 $\mathrm { A } _ { 3 3 }$ 。以此构建线性生产建设项目弃渣场失事危害程度快速评价模型。

## 3 权重的确立

随着不同学科的交互融合，近年来各种新的理论和方法被引入到科学决策系统的综合评价当中，其中很多都是对赋权方法的改进与创新，指标权重的赋予方法分为主观赋权法和客观赋权法，主观赋权法如传统的层次分析法、灰色理论等均在一定程度上依赖于专家的咨询意见，客观赋权法是直接根据评价对象的各个指标的原始信息经过一定数学处理后获得权重的方法，它具有较强的数学理论依据，但未考虑评价者的偏好，要求较多的样本、原始信息质量要求高，并且求解过程也相对复杂，本文选取了两类经典且具有代表性的赋权方法，即层次分析法(主观赋权法)和熵权法(客观赋权法)，分别计算出权重后，通过 Spearman秩对两类权重进行集成，使本文运用的权重同时兼具主观和客观方法的共同优势。

## 3.2 熵权法

熵(Entropy)，最先应用于热力学和统计物理领域，在热力学领域，熵是热能转换中热能有效利用程度的度量，一般熵值越大，说明系统的热能有效利用程度低;熵值越小，说明系统的热能有效利用程度高。

在统计物理领域，熵主要用于度量分子运动的无序程度，一般熵值越大，说明系统的分子运动无序程度高；熵值越小，说明系统的分子运动无序程度低。

在综合评价领域，运用信息熵对弃渣场失事危害程度进行评价所获取的系统信息及信息的效应值是很自然的，与统计物理中熵函数形式是一致的。

熵权法计算出的指标权重较层次分析法更为客观，具有较高的可信度，但是由于缺乏各项评价指标之间的横向比较，且需要一定的数量的样本数据，在应用上受到一定的限制，一般建议在拥有大量原始数据的前提下选用。本文选用湖北省鄂北地区水资源配置工程为例进行客观权重的试算，湖北省鄂北地区水资源配置工程共产生永久弃土170.68万m³,产生永久弃石渣1067.09万 $\mathrm { m } ^ { 3 } \left( \begin{array} { l l l } \end{array} \right.$ 均为松方)，合计1237.77万 $\mathbf { m } ^ { 3 }$ ,确定选择弃渣场共计113处，其中弃土场22处(含沟道弃土场3处、坡地弃土场7处、平地弃土场12处)、弃石场91处(含沟道弃石渣场62处、坡地弃石渣场13处、平地弃石渣场16处)，符合本模型的样本大数据要求，通过计算，得出熵权法权重为：

## 3.3 拉格朗日组合模型

由于每一种赋权方法的原则和思路并不相同，所以理论上应当尽量将多种类型的权重进行融合，遵循集多种赋权方法之所长的思想。力求在权重确立过程中更加恰当和准确。本文采用拉格朗日组合模型对 $W _ { \mathrm { A H P } }$ 和 $W _ { \textrm { s } }$ 进行组合，主要方法如下：

假设赋权方法A的权重向量为 $\alpha _ { i }$ ,赋权方法 B的权重向量为 $\beta _ { i }$ ,选用拉格朗日组合公式来融合方法A和方法B计算得到的权重，称之为拉格朗日组合赋权法：

$$
W _ { i } = \frac { \sqrt { \alpha _ { i } \beta _ { i } } } { \sum _ { i = 1 } ^ { n } \sqrt { \alpha _ { i } \beta _ { i } } } \vert i = 1 , 2 , 3 , \cdots n \vert
$$

由此确立拉格朗日组合权值 $\mathbb { \boldsymbol { W } } _ { i }$ 作为弃渣场失事危害程度快速评价的权重:

$$

## 5 结论

(1)弃渣场失事对主体工程或环境的危害程度难以确定，本文引入弃渣场失事危害程度快速评价的概念，以量化弃渣场失事的危险程度。

(2)本文采用层次分析法和熵权法两类赋权方法来确立弃渣场失事危害程度评价体系的权重，并引入拉格朗日组合模型改善主观和客观权重的非一致性问题。

(3)通过构建弃渣场失事危害程度快速评价的五个等级以及评价指标，并通过现行规范和研究成果确立各指标的评价阈值，将弃渣场危害性评价的繁复系统尽可能量化，实现弃渣场的快速设计，但众多问题仍需要进一步完善，评价指标的实用性和前瞻性是今后研究的重点。

(4)本文仅采用公路工程作为实例进行研究，未对各类生产建设项目进行系统性分析，今后将运用弃渣场失事危害程度快速评价模型展开长序列、不同类型项目的研究工作。
