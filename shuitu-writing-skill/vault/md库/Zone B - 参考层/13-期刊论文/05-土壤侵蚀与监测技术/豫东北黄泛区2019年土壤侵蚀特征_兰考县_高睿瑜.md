黄泛平原风沙区（以下称<sup>“</sup>黄泛区<sup>”</sup>）属国家级水土流失重点预防区 <sub>，</sub> 长久以来<sub>，</sub> 风蚀和水蚀造成土壤养分流失 土地生产力下降<sup>［1］</sup> 破坏区域生态环境 制约经济社会发展 黄泛区地处暖温带季风性气候区雨热同期 风旱同季 地势整体平坦 区域在1—5月和10—12月同时存在强风和干旱天气 <sub>，</sub>导致耕地 林草地和沙地上易出现风蚀 降水集中在6—9月 加之局部存在沙丘 沙岗等微起伏地貌<sup>［2］</sup> 易造成一定程度的水蚀 为摸清黄泛区风蚀规律 明确水土流失防治的的重点时间 <sub>，</sub> 应对区域土壤侵蚀分布格局 年内变化特征进行研究

目前 国内关于黄泛区土壤侵蚀的研究侧重于风蚀 早期以试验分析和定位观测为主 比如赵存玉等<sup>［3］</sup>结合风洞模拟 野外调查阐明了鲁西北黄泛区农田与风蚀的作用机制<sub>；</sub>姬生勋等<sup>［4］</sup>证明了不同土地利用方式下土壤风蚀量变化规律存在差异 <sub>；</sub>2017年 宋胜明等<sup>［5］</sup>通过定位观测研究了风速累积时间 农作物覆盖情况 地表粗糙度对兰考县耕地风蚀的影响 近

10a 遥感监测 模型计算被应用于黄泛区土壤侵蚀研究 内容涉及风蚀和水蚀 2012年 王友胜<sup>［2］</sup> 借助遥感监测和野外调查研究了淮河流域黄泛区风水侵蚀格局及其驱动因子 为黄泛区土壤侵蚀后续研究提供了参考和有力依据 毛玉磊<sup>［6］</sup>利用遥感技术系统分析了河南黄泛区易风蚀性土地的现状及变化特征2019年<sub>，</sub>高分辨率（≤2m）遥感影像广泛应用于水土流失动态监测 <sub>，</sub> 袁利等<sup>［7］</sup> 张乐<sup>［8］</sup> 以高分辨率遥感影像为数据源<sub>，</sub> 利用风蚀模型 CSLE模型分别研究了淮河流域黄泛区 鲁西北黄泛区的水土流失情况 随着基础数据质量和遥感影像分辨率提高 <sub>，</sub>县域尺度土壤侵蚀研究增多<sup>［9－10］</sup> 但目前黄泛区土壤侵蚀多以年为时间尺度进行现状和分布格局研究 有关土壤侵蚀年内变化特征关注较少 有待进一步丰富

本研究以河南省兰考县为研究区域 以高分辨率遥感影像 MODIS－NDVI和SMAP等影像为基础数据<sub>，</sub>借助风力侵蚀模型和CSLE模型对兰考县土壤侵蚀进行系统研究 探索土壤侵蚀及其影响因子2019年年内半月变化特征 综合分析区域全年侵蚀特征 以期丰富黄泛区土壤侵蚀研究成果 为确定黄泛区及黄河下游地区风蚀治理的重点时间 地区提供科学依据 为全国水土流失动态监测工作提供数据支持

## 1 研究区概况

河南省兰考县属于淮河流域黄泛区 地理位置位于34．44°—35．01°N 和 $1 1 4 . 4 0 ^ { \circ } - 1 1 5 . 1 6 ^ { \circ } \mathrm { E }$ 的范围内（具体情况见图1） 总面积为1116km<sup>2</sup> 包括仪封乡三义寨乡 城关镇 东坝头乡等15个乡镇 研究区属暖温带半湿润季风性气候 四季分明 雨热同期 冬春季降水少<sub>，</sub>大风较多<sub>；</sub>冬季平均风速为1．71m／s<sub>，</sub>春季平均风速1．89m／s2月风速值最高 为 $5 . 9 0 ~ \mathrm { m / s } \sim$ $1 0 . 9 5 ~ \mathrm { m } / \mathrm { s } ^ { [ 1 }$ <sup>0］</sup> <sub>。</sub> 区域地貌以平原为主<sub>，</sub> 存在冲积扇<sub>、</sub>沙丘 沙岗等地貌景观<sub>；</sub>地形平坦<sub>，</sub>以平缓坡为主 豫东北黄泛区植被属暖温带落叶阔叶林带 种植农作物 农田林网 经济林 防风固沙林<sub>，</sub>常见树种为杨树苹果等 农作物多为一年两熟制耕作 <sub>，</sub>主要为小麦与花生 玉米或地瓜轮作<sub>；</sub>部分区域存在一年一熟制 是风蚀易发生区域 农田风蚀与风沙化是区域的主要水土流失问题<sup>［10］</sup>

## 4 讨论与结论

（1） 兰考县风力因子半月变化呈 <sup>“</sup>M<sup>”</sup> 型 第3—9<sub>，</sub>21—22个半月值较高<sub>；</sub> 表土湿度因子变化呈<sup>“</sup>波浪型<sup>”</sup> <sub>，</sub>第13—18个半月值较高 降雨侵蚀力因子 林园草植被覆盖与生物措施因子 B 均值的变化为<sup>“</sup>先升高再降低<sup>”</sup> <sub>，</sub> 前者第9—16个半月值较高<sub>，</sub> 后者第12—18个半月值较高

（2） 兰考县半月风蚀模数变化呈<sup>“</sup>波浪型<sup>”</sup> 全年累计风蚀模数在 $0 { \sim } 5 ~ 1 8 6 . 3 1 ~ \mathrm { t } / ( \mathrm { k m } ^ { 2 } ~ \bullet ~ \mathrm { a } )$ 范围内<sub>，</sub>均值为153．26t／（km<sup>2</sup> · a） <sub>；</sub> 第4—9<sub>，</sub>21—22个半月风蚀较强 仪封乡 张君墓镇等风蚀模数较高 风蚀多在水浇地<sub>、</sub>采矿用地上 与前人相似研究比较<sup>［7</sup>，<sup>10］</sup> <sub>，</sub> 风蚀空间分布特征相近

（3） 兰考县半月水蚀模数变化趋势为<sup>“</sup>先升高再降低<sup>”</sup><sub>；</sub>全年累计水蚀模数在0～8028．86t／（km<sup>2</sup> ·a）范围内 均值为9．54t／（km<sup>2</sup> ·a） <sub>；</sub>第12—18个半月水蚀相对较强<sub>；</sub>东坝头乡 城关镇存在水蚀模数较高区域 水蚀多在采矿用地上

（4） 2019年兰考县共17个半月出现水土流失占全年的70．83％<sub>；</sub> 第4—9个半月水土流失面积最多<sub>；</sub>均为风蚀 全年水土流失面积为271．66km<sup>2</sup><sub>，</sub>占全县面积的24．34％ 主要为轻度风蚀 占水土流失面积的96．83％ 风蚀主要在仪封乡 张君墓镇 谷营镇和东坝头乡 水蚀主要在仪封乡 水土流失监测与防治应重点关注此时间内水浇地 采矿用地上的侵蚀 本研究所得兰考县水土流失面积与前人相似的研究<sup>［7</sup>，<sup>10］</sup>比较有所差异 由研究区域差异导致<sub>；</sub> 但风蚀空间分布特征相似 证明了本研究结果的准确性 合理性
