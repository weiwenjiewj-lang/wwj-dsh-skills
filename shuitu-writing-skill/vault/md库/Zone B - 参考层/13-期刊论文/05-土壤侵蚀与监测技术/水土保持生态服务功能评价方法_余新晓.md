# 水土保持生态服务功能评价方法

余新晓，吴岚，饶良懿，李静锐，杨永强(水土保持与荒漠化防治教育部重点实验室北京林业大学水土保持学院，100083，北京)

摘要 由于生态系统服务功能支撑与维持着地球生命系统的平衡与稳定，因此它已受到当今世界普遍关注。在我国水土流失严重的情况下，运用生态服务功能理论可以正确评价水土保持措施的作用，并为合理的生态建设规划提供依据。本文在总结Costanza等人理论的基础上，分析水土保持各项措施对保护和改良人类赖以生存的自然环境条件的综合效用。认为水土保持生态服务功能包括保护和涵养水源、保护和改良土壤、固碳释氧、净化空气和防风固沙等功能。另外，本文从水土保持工程措施、水土保持农业措施和水土保持林草措施3个方向为上述功能筛选了10个评价指标，且为各个指标分别建立了评价方法。这些指标及方法将有助于对水土保持措施的生态环境效应进行深入的分析与评价。

关键词 生态服务功能；水土保持；评价方法

Abstract How to maintain the ecological services of ecosystem is a very popular problem, because it support the balance and keep the stabilization of the eco-environment · And it is also the base of sustainable develop ment · This paper, based on the Costanza 's theory and others, after analyzing the aggregate functions of soil and water conservation measures, defined the ecological services of soil and water conservation as an aggregate function which can protect and improve the eco-environment · The ecological function included such as conserv ing water resource, preventing soil losses, carbon fixation 博releasing oxygen, cleaning air, and fixation sand . Those functions were subdivided by 10 indexes based on the scientific, practical, and acceptable ways· And every index had been constructed in the computing formula· Thus, those formulas could help to appraise the e cological functions of soil and water conservation measures correctly .

Key words ecological function; soil and water conservation; assessment methods

我国现有水土流失面积为356万 ${ \mathrm { k m } } ^ { 2 }$ 其中受水力侵蚀的水土流失面积165万 $\mathrm { k m } ^ { 2 }$ 受风力侵蚀的水土流失面积191万 $\mathrm { k m } ^ { 2 }$ ，在水蚀和风蚀面积中，有26万 $\mathrm { k m } ^ { 2 }$ 为水蚀风蚀交错区[1]。由此可见，水土流失已成为各种生态退化的集中反映，同时也是导致生态恶化的重要根源。治理水土流失、保护和建设良好生态环境是可持续发展的前提和基础，也是保证国土生态安全的根本大计。近些年来，我国的水土保持工作已取得了飞速发展，但在此方面的研究工作多局限于具体措施及方法的研究，有关全面系统地评价水土保持生态效益的研究还比较少。笔者从生态服务功能入手，着重阐明水土保持生态服

务功能的评价方法。

## 1 水土保持生态服务功能分析

## 1.1 水土保持生态服务功能含义

在总结Costanza等[2-3]关于生态服务功能概念的基础上，笔者认为水土保持生态服务功能是指在水土保持过程中所采用的各项措施对保护和改良人类及人类社会赖以生存的自然环境条件的综合效用，包括保护和涵养水源功能、保护和改良土壤功能、固碳释氧功能、净化空气功能和防风固沙功能。

## 1.2 水土保持生态服务功能构成

1.2.1 保护和涵养水源功能 水土保持措施的重要功能是保持水土，其拦截径流作用非常显著。例如，在黄土地区坡地修水平梯田保水率达85%～95%，修坡式梯田保水率达78%～85%，修地埂保水率达75%～80%，修灌木防冲带保水率达70%～75%[4]，经工程和植物措施相结合治理的侵蚀沟保水率达75%～85%[5]。同时，林草措施具有截留降水、增强土壤下渗、抑制蒸发及缓和地表径流等功能。1.2.2 保护和改良土壤功能 用于保持水土的林草植被可截留降雨，减弱雨滴的冲击和侵蚀。同时，林地土壤具有较高的透水性和蓄水性，使得地表径流最大限度地转变为地下径流。另外，它们的根系具有固结土壤、减少滑坡和泥石流的作用[6]。在坡耕地，水土保持工程措施和水土保持农业措施可有效拦蓄降雨，防止径流产生，增加土壤养分，大幅度提高粮食产量[7-8]。

1.2.3 固碳释氧功能 此项功能以水土保持林草措施最为突出。植物通过第一性生产将 $\mathrm { C O _ { 2 } }$ 固定在各种器官和组织中，同时释放所有动物生存不可缺少的物质—氧气 $\left( 0 _ { 2 } \right)$ ，因此，林草措施对维护大气中的 $\mathrm { C O _ { 2 } }$ 的稳定具有重要作用，成为氧气的“天然制造厂”[9-11]

1.2.4 净化空气功能 该项生态服务功能也主要是由林草措施带来的。植物的树干、枝叶可以吸收污物、阻滞粉尘和降低噪声[12]，另外有些树木能分泌具有杀菌或抑菌能力的挥发性物质。研究[10]表明， $\mathrm { { l } _ { h m } } ^ { 2 }$ 生长良好的森林，每年吸收 $\mathrm { S O 2 }$ 12 t, 固定尘埃 $7 5 0 \mathrm { t }$ ,并可杀灭空气中的细菌。

1.2.5 防风固沙功能 当风经过防风固沙林时，会受到来自树干和枝叶的阻挡，并且气流本身也会相互冲撞摩擦，使得风力削弱，风速降低，从而削弱了风的撞染能力；困此防风固沙林可有效地阻截、固定、控制流沙，在防沙治沙、防治沙尘暴等方面会起

到重要的作用[13-14]。

## 2.1 水土保持工程措施生态服务功能评价方法

水土保持工程措施按其作用分为山坡防护工程、山沟治理工程、山洪排导工程和小型蓄水用水工程。但在计算生态服务功能时，这种分类方法过于细致，笔者将其分为两种情况进行计算：一是将已淤满的坝地、谷坊看作有埂梯田，采取和梯田相同的计算方法;另一种是未淤满的坝地和谷坊的计算方法。2.1.1 有埂梯田 有埂梯田水土保持工程措施生态服务功能计算方法如下。

1) 减少洪水流量计算公式[4]

$$
{ \cal T } _ { \mathrm { w } } { } ^ { = } A _ { \mathrm { g } } w ^ { \eta }
$$

式中： $T _ { \mathrm { w } }$ 为已淤满坝地、谷坊或有埂梯田减少洪水流量,万 $\mathbf { m } ^ { 3 } ; A _ { \mathrm { g } }$ 为已淤满的坝地、谷坊面积或梯田面积， $ { \mathrm { h m } } ^ { 2 } ; w$ 为计算年流域天然状况下的产洪模数，可以根据流域水量平衡原理来试算确定， $\mathrm { { m } ^ { 3 } / \mathrm { { k m } ^ { 2 } } }$ ; η为减洪系数，如在黄土高原地区，有埂梯田η取1.0[4]

2) 拦截泥沙量计算公式[7]

$$
T _ { \mathrm { s g } } { = } A _ { \mathrm { g } } \gamma _ { \mathrm { s } } ( 1 { - } \alpha ) ( 1 { - } b )
$$

式中： $T _ { \mathrm { s g } }$ 为已淤满坝地、谷坊或有埂梯田拦截泥沙量，万t; $\boldsymbol { \gamma } _ { \mathrm { s } }$ 为拦泥定额，即单位面积的拦截泥沙量，万 $\mathrm { { t / h m } ^ { 2 } }$ ;α为人工填垫及坝地两岸坍塌形成的坝地面积占总面积的比例，如在黄河中游地区，α取0.1～0.2;b为推移质在拦泥量中所占比例系数，如黄河地区 b 为0.1[4]。

2.1.2 未淤满坝地 未淤满坝地水土保持工程措施生态服务功能计算公式如下。

1）减少洪水流量计算公式，可根据计算区内所有坝系拦截泥沙总量进行反推

$$
{ T _ { \mathrm { w } } { = } k T _ { \mathrm { s g } } ^ { ' } } / { \ell _ { \mathrm { s } } }
$$

式中： $T _ { \mathrm { s g } } ^ { ' }$ 为计算区内全部坝系拦截泥沙总量，万t;$\boldsymbol { \rho } _ { \mathrm { s } }$ 为泥沙的密度， $\mathrm { _ t } / \mathrm { _ m } ^ { 3 }$ ，黄土高原地区取 $1 . 3 5 { \mathrm { ~ t } } / { \mathrm { m } } ^ { 3 }$ k为流域内坝系淤地拦洪时的洪沙比，据黄河水利委员会绥德水土保持科学试验资料分析[4]，河龙区间 k值在1.433至2.4 之间，泾河北洛河流域 k值分别为 2.462和 2.652,渭河流域 k 值在1.5 至 2.0之间。

2）拦截泥沙量计算公式，这一部分因缺乏实测资料而无法直接算出，但在坝地、谷坊中的拦截泥沙总量占有一定比重。那么，未淤满的坝地每年拦截泥沙量可用当地坝系、谷坊淤满后的总拦截量除以此坝系或谷坊的淤满年限算出，例如，在黄土高原区，淤地坝一般在12a左右淤满。

3）减少土壤侵蚀量计算公式，工程措施的减少土壤侵蚀作用在措施建成后即行开始，直至坝系淤满后基本不再发挥作用。其数量一般与沟壑密度、沟道比降及沟谷侵蚀模数有关，按侵蚀原理计算较难，通常是在土壤侵蚀模数的基础上乘以扩大系数来计算[4,7]：

$$
T _ { \mathrm { n } } { } ^ { = } A _ { \mathrm { t } } d m n
$$

式中： $T _ { \mathrm { n } }$ 为未淤满坝地年减少土壤侵蚀量，万t； $A _ { \mathrm { t } }$ 为计算区内仍处于淤地状态的淤地坝面积， $\mathrm { { h m } ^ { 2 } }$ ; d为流域内的平均侵蚀模数， $\mathbf { t } / ( \mathbf { k m } ^ { 2 } \cdot \mathbf { a } ) ; m$ 为沟谷侵蚀量与流域平均侵蚀量之比，%，例如西峰水土保持科学试验站测南小河沟流域多年平均侵蚀模数为$6 8 7 0 \mathbf { t } / ( \mathbf { k m } ^ { 2 } \cdot \mathbf { a } )$ ，沟谷地为 $1 5 2 0 0 \mathrm { t } / ( \mathrm { k m } ^ { 2 } \cdot \mathrm { a } ) ^ { [ 4 ] }$ ,若忽略面积的影响，则黄土高原沟壑区的m值为2.20;n为坝地以上沟谷侵蚀的影响系数。

## 2.2 水土保持农业措施生态服务功能评价方法

适宜的水土保持农业措施既能创造结构良好的疏松由屍网能调节土壤忠w氣水分作物之间的协合关系，可以起到控制水土流失和提高作物产量

的双重作用[15];因此，水土保持农业措施生态服务功能应从拦蓄径流、减少土壤侵蚀以及保存土壤肥力3个方面进行评价。

1）拦蓄径流量计算公式

$$
{ \cal T } _ { \mathrm { t } } { } ^ { } = p H \ r { \cal A } _ { \mathrm { n } }
$$

$$

$$

式中： $d ^ { ' }$ 为计算区内未采取水土保持农业措施时的土壤侵蚀模数， $\mathbf { \gamma } _ { \mathbf { t } } / ( \mathbf { h m } ^ { 2 } \cdot \mathbf { a } ) \ ; \ \beta$ 为保土率，%。

3）保存土壤肥力，此部分是指农业措施减少流失的土壤中所具有的肥力，其计算方法为

$$
T _ { \mathrm { f } } { = } \sum \mathrm { T } _ { \mathrm { n } } C _ { i } ( i { = } \mathrm { N } , \mathrm { P } , \mathrm { K } )
$$

## 2.3 水土保持林草措施生态服务功能评价方法

## 3 结论与讨论

生态服务功能的特征是，不但具有地域性而目与当地的经济发展水平有关；因此，生态服务功能的分析既要与国际上的同类研究相衔接，又要具有鲜明的区域特色。功能指标的选取要切实符合客观实际，如照搬照抄则会失去评价分析的意义。

Costanza的生态系统服务功能框架是在一个广泛的生物群落系列赋予的，但用于某一具体生态系统或生态措施则显得有些宽泛；因此，用具体指标进行细划就变得尤为重要。细划时应考虑生态系统的种类、结构等多种因素，而且还应考虑空间的位置及区域特性，这一方面的问题有待进一步提高。

水土保持措施为人类提供了巨大的生态效益，在改善水土流失方面产生了显著的影响。笔者通过分析水土保持措施对生态系统服务功能的影响，根据科学性、独立性以及可操作性原则，将水土保持生态系统服务功能分为保护和涵养水源、保护和改良土壤、固碳释氧、净化空气和防风固沙等5项功能，并构建了上述功能的分析指标体系。

由于水土保持工程措施、水土保持农业措施与水土保持林草措施的作用原理及发挥的效果不一致；因此，3种措施在减少洪水流量、拦截泥沙、减少土壤侵蚀方面的生态功能评价方法各不相同，而且，水土保持林草措施还在固碳释氧、净化空气功能和防风固沙生态服务功能方面具有独立的评价方法。
