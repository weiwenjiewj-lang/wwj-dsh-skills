【编者按】2016年1月5日，习近平总书记在重庆主持召开推动长江经济带发展座谈会，明确提出“共抓大保护，不搞大开发”，长江经济带发展战略由此全面实施。10a来，沿江各省(自治区、直辖市)及相关部门深入贯彻习近平生态文明思想和习近平总书记关于治水的重要论述，坚持生态优先、绿色发展，统筹推进长江流域水土流失综合治理，流域生态环境发生转折性变化，水土保持工作取得显著成效，为长江经济带高质量发展提供了坚实支撑。

值此战略实施10周年之际，《中国水土保持》编辑部组织开展了“纪念长江经济带发展战略实施10周年暨长江流域水土保持与生态文明建设”专题征稿活动，得到广大作者积极响应。本期专栏围绕长江流域水土保持与生态文明建设，集中展示战略实施10a来水土保持工作在宏观总结、区域治理、监测评价、城市水土保持等方面的实践进展与经验成果，探讨新形势下水土保持服务国家战略的重点方向和实施路径。专栏文章既有对长江流域整体保护治理的系统思考，也有重庆、江西、湖南、上海等地不同区域、不同类型的典型实践，可为水土保持工作者总结经验、交流成果、凝聚共识提供参考，为推动长江流域水土保持与生态文明建设高质量发展贡献智慧力量。

## 1 面临的形势和要求

长江流域水土流失分布广泛，是我国水力侵蚀面规模化农林开发易诱发人为水土流失，潜在侵蚀风险较高。

习近平总书记多次在长江经济带发展座谈会上，就加强长江保护治理作出一系列重要讲话和指示批示。2016年1月，在推动长江经济带发展座谈会上指出，“当前和今后相当长一个时期，要把修复长江生态环境摆在压倒性位置，共抓大保护，不搞大开发”，走生态优先、绿色发展之路，使中华民族母亲河永葆生机活力。2018年4月，在深入推动长江经济带发展座谈会上指出，“正确把握整体推进和重点突破的关系，全面做好长江生态环境保护修复工作”。2020年11月，在全面推动长江经济带发展座谈会上指出，“推进长江上中下游、江河湖库、左右岸、干支流协同治理，改善长江生态环境和水域生态功能，提升生态系统质量和稳定性”。2023年10月，在进一步推动长江经济带高质量发展座谈会上指出，“要从人与自然和谐共生的生命共同体出发，着眼中华民族永续发展，把长江保护好”。习近平总书记的系列重要讲话和指示批示，系统擘画了长江流域生态治理路径，为新时代新征程长江流域水土保持工作指明了发展方向，提供了根本遵循。

水土保持是江河保护治理的根本措施，是生态文明建设的必然要求。长江流域是长江经济带的自然基础和空间载体，长江经济带发展战略的全面实施，对长江流域水土保持工作赋予了新的使命，提出了新的更高要求。

## 2 主要做法和成效

长江流域牢固树立和践行“绿水青山就是金山银山”的理念，坚持流域观念、流域立场、流域思维，统筹推进山水林田湖草沙一体化治理保护，水土保持取得显著成效，走出了一条高质量发展的新路子。2018一2025年，长江流域水土流失面积减少6.85万km²，减幅达10.47%，其中中度及以上土壤侵蚀面积减幅达35.78%，实现了水土流失面积和强度持续“双下降”。

## 2.1 强化统筹协同，水土保持工作机制持续完善

长江上游水土保持委员会连续召开第十六次、十七次、十八次会议，以学习贯彻习近平生态文明思想和习近平总书记关于推动长江经济带发展重要讲话精神为主题，加强组织领导，强化统筹协调，研究部署长江流域水土保持重点任务和工作措施。长江水利委员会(以下简称“长江委”)联合流域19省(自治区、直辖市），建立长江流域水土流失联防联控联治工作机制，强化流域水土保持工作的统一治理管理。长江委和流域各省(自治区、直辖市)均出台加强新时代水土保持工作的文件和实施方案，量身定制新时代水土保持高质量发展路线图。全流域构建了省、市、县三级水土保持率目标体系，细化落实地方政府水土保持目标责任制和考核制度；建立健全由省委、省政府领导为召集人，相关职能部门负责同志为成员的水土保持联席会议制度，加快构建党委领导、政府负责、部门协同、全社会共同参与的水土保持工作格局。

## 2.2 加强源头防控，水土流失预防保护稳步推进

聚焦抓好水土流失源头防控，依法划定水土保持重点区域，制定水土保持空间管控制度，为科学实施差别化保护治理措施提供基础支撑。青海、四川、西藏、云南、重庆、湖北、湖南、江西、安徽、甘肃、陕西、河南、贵州、广西、福建等省(自治区、直辖市)划定了15个国家级水土流失重点防治区共27.02万km²，使1.69万条小流域落地上图，确定了生产建设项目选址选线避让区域，明确了减少人为扰动、保护地表植被等管理要求。青海、云南、贵州、四川等地以江河源头区、岩溶石漠化区和金沙江干热河谷区等水土流失敏感脆弱区为重点，完成水土流失严重、生态脆弱区划定落地，划定面积1.10万km²，涉及生态保护红线1.09万km²，明确了禁止开展可能造成水土流失的生产建设活动范围。流域各省(自治区、直辖市)积极推进禁止开垦陡坡地范围划定，并同步完成公告发布。长江流域连续8a实现水土流失动态监测全覆盖，及时掌握了全流域及重点区域、重要支流水土流失及动态变化情况。

## 2.3 从严执法管控，人为水土流失监管全面加强

依法严格人为水土流失监管，严控人为水土流失增量。一是加强生产建设项目水土保持全链条全过程监管。10a来，各级水行政主管部门审批水土保持方案27.40万个,开展水土保持监督检查37.90万个(次)，督促12.19万个项目开展水土保持设施验收，实现从立项到运营的全生命周期监管。二是加强重点区域重大项目协同监管。长江委会同地方水行政主管部门，连续5a开展成渝地区双城经济圈水土保持联合监管，常态化开展丹江口库区及其上游流域水土保持跟踪预警，加强跨区域铁路、水电、管道等重大工程联合监管。三是依法查处水土保持违法违规行为。10a来，各级水行政主管部门立案查处水土保持违法案件1.88万件。2019年，水利部开展长江经济带生产建设项目水土保持监督执法专项行动，组织长江经济带11省(自治区、直辖市)查处水土保持违法违规项目2万余个[2]。四是全覆盖、常态化开展水土保持遥感监管。自2019年起，水利部每年组织开展1次全覆盖遥感监管，2020—2025年，长江经济带每年认定查处的违法项目从1.32万个降为0.26万个，违法项目逐年下降。各省(自治区、直辖市)每年加密开展2\~3次遥感监管，全面监控、及时发现、精准判别人为水土流失。五是加快实施水土保持信用监管。长江委归集、整理水利部批复项目信用信息，并按要求报送水利部;流域各省(自治区、直辖市)全面开展区域内市场主体水土保持信用评价，形成闭环管理。

## 2.4 深化精准治理，水土流失治理提质增效

坚持问题导向和需求导向相统筹，实施分区分类精准化治理，持续推进水土流失综合治理提质增效。10 a来，长江流域治理水土流失面积20.35万 $\mathrm { k m } ^ { 2 }$ ,建设生态清洁小流域860条，水土保持率提高到82.67%,水土流失面积和强度持续下降，水土保持功能和生态产品供给能力持续提升。2024年，增发国债丹江口库区水土流失治理项目顺利实施，治理水土流失面积 $4 ~ 7 5 7 ~ \mathrm { k m } ^ { 2 }$ ，提前完成丹江口库区及其上游流域水土保持“十四五”规划治理任务。各地积极践行“绿水青山就是金山银山”理念，水土保持生态产品价值转化迈出坚实步伐。据不完全统计，“十四五”以来，长江流域完成水土保持生态产品价值转化交易150余单，包括物质供给、调节服务、文化服务、新增耕地指标等，交易总金额13.56亿元，获绿色金融授信近9亿元。实践中，四川、重庆、陕西、湖北、湖南、江西等省(直辖市)开展一体化推进水土保持工程建设，以县域为单元，以水源区、库区、城镇周边为重点，实施治山保水、治河疏水，统筹治污洁水，打造小流域产业综合体，推进水土保持生态产品转化交易实现，探索建立水土保持投入循环机制。

## 2.5 夯实基础工作，水土保持能力不断提升

一是发挥规划引领作用，高质量编制完成长江流域(片)水土保持规划，构建由长江澜沧江源及金沙江上游、藏北内陆河湖区、雅鲁藏布江中下游、嘉陵江岷江上游、湘资沅澧上游、大别山南麓诸水系等六个水土流失预防带，金沙江下游、嘉陵江岷沱江中下游、乌江赤水河流域、西南诸河高山峡谷区等四个水土流失治理片，丹江口库区及上游、三峡库区、赣江抚河上中游等三个水土保持功能提升区组成的“六带四片三区”水土流失重点防治布局，明确防治目标和重点任务，统筹流域上中下游、左右岸、干支流水土流失协同治理。二是水土保持监测能力显著提升。稳步推进国家水土保持监测站点优化布局工程长江流域(片)64个监测站点建设，推动构建三峡库区、丹江口库区等重点区域水土保持监测网络体系，推进省级监测站点优化布局提档升级；水土流失动态监测由重点区域监测转向全覆盖监测，自2018年起，连续8a实现长江流域动态监测全覆盖；同时，完成长江经济带云贵川渝鄂5省(直辖市)133万 $\mathrm { k m } ^ { 2 }$ 范围坡耕地专项调查。三是水土保持信息化建设持续推进，构建长江流域水土保持数字化场景，建设水土保持“一张图”。重庆市开发“水土保持智管”应用系统，安徽省建成“皖土智配”土石方综合利用平台，贵州省完成133万个水土流失图斑落地。此外，长江委制定水土保持科研工作顶层设计方案，大力推进水土保持基础研究与关键技术攻关，为流域治理提供科技支撑。

## 3 存在的问题

在全流域的共同努力下，流域水土保持工作取得了积极成效。然而，对标对表生态文明建设、重大国家战略、粮食安全和乡村振兴、水利高质量发展等要求，以及建设安澜长江、生命长江和幸福长江的需要，流域水土保持工作仍面临着一些亟待解决的问题和不足。

1)水土流失减存量任务重。截至2025年，全流域仍有水土流失面积31.04万 $\mathrm { k m } ^ { 2 }$ ，占长江流域面积的17.33%，金沙江下游、岷沱江中下游、三峡库区、乌江和赤水河上中游等区域的水土流失面积占比近30%，长江上中游的近亿亩 $( \ 1 5 \ \overrightarrow { \mathrm { E H } } = 1 \ \mathrm { h m } ^ { 2 } \ )$ 坡耕地和南方红壤区的近万个崩岗亟待治理。

2)水土流失控增量压力大。长江经济带是我国社会经济活动最活跃的区域之一，人口和经济总量占全国比重均超40%，城镇化发展和交通、能源、水利等基础设施建设规模仍保持在较高水平，人为水土流失潜在风险高，控制人为水土流失增量的监管压力依然很大。

3)治理提质增效尚需全面提升。水土流失防治体系还不完善，以流域水系为单元，整沟、整村、整乡、整县一体化推进小流域综合治理尚需加强。生态清洁小流域建设仍需加快，生态产品的供给能力和水土流失治理的科学性、系统性还有待提升。水土保持投入和生态补充机制尚不完善。

4)基础支撑能力不足。水土保持监测体系尚不完善，监测成果质量有待进一步提升:水土流失模型参数优化和水土流失图斑落地应用仍需加强。信息化建设和数据共享能力存在短板，科技创新平台和技术服务体系尚需完善，管理能力和水平还需提升。

## 4 对策措施

以习近平生态文明思想为指导，全面贯彻落实习近平总书记“节水优先、空间均衡、系统治理、两手发力”治水思路和关于治水的重要论述，聚焦落实《中华人民共和国水土保持法》《中华人民共和国长江保护法》《中华人民共和国青藏高原生态保护法》等法律要求，牢固树立和践行“绿水青山就是金山银山”理念，以推动高质量发展为目标，以落实落细《关于加强新时代水土保持工作的意见》为主线，以服务全面推动长江经济带发展等重大国家战略为重点，推进水土流失系统治理、综合治理、源头治理，提升流域水土保持管理能力，构建水土流失防治新格局，实现水土保持率“十五五”期末达83.8%以上,2035年达85%以上，为建设安澜长江、生命长江、幸福长江提供坚强支撑[2]。

## 4.1 持续深化水土保持体制机制创新

牢固树立“大水保”理念，深化党委领导、政府负责、部门协同、全社会共同参与的水土保持工作格局[3-4]。充分发挥长江流域水土流失联防联控联治工作机制作用.把握好生态系统的整体性和流域的系统性规律，强化流域统一管理治理。健全各级水土保持工作协调机制，强化政策支持协同，充分调动社会各方力量，形成工作合力5]。建立完善水土保持生态产品价值实现机制、水土保持投入循环机制和水土保持多元化投入机制，鼓励和引导社会资本参与水土流失治理。

## 4.2 全面加强水土流失防控

加强水土流失源头防控，建立健全水土保持空间管控制度，加强水土流失重点防治区管理，严格水土流失严重、生态脆弱区域管控，落实禁止开垦陡坡地范围管理要求[5]。加强长江源头区及金沙江上游高山草甸、天然草原和湿地的保护，提高水源涵养能力；强化嘉陵江、岷江、湘江、资水、沅江、澧水上游，以及大别山南麓诸水系等源头区的封育保护，促进生态自然修复；加大丹江口水库和三峡水库等国家战略水源地预防保护力度，维护水库水质和库容安全，有力支撑“碧水东流”生态格局，保障“一泓清水永续北上”。

## 4.3 加快推进重点区域综合治理

以国家级水土流失重点治理区为主，大力推进金沙江下游、嘉陵江上游、三峡库区、乌江赤水河上中游、岷沱江中下游等区域的综合治理和赣江抚河上中游崩岗治理。全力推进南水北调中线水源区、三峡库区等重点区域生态清洁小流域建设，提升水土保持功能和生态产品供给能力。将小流域综合治理纳入经济社会发展规划和乡村振兴规划，建立统筹协调机制，以流域水系为单元，开展整沟、整村、整乡、整县一体化水土保持工程建设[3]。“十五五”期间，将新增水土流失治理面积10.29万km²，其中国家水土保持重点工程治理面积2.5万km²，建设生态清洁小流域707条，治理崩岗3700座。

## 4.4 依法严格人为水土流失监管

严格落实相关法律明确的水土保持监管规定，加强生产建设项目全链条全过程监管。加大信息化监管力度，推动遥感监管实现全覆盖、常态化，提升监管精准化、智能化水平，做到全面监控、及时发现、精准判别4]。全面实施水土保持信用评价，健全守信激励和失信惩戒机制。强化跨部门协同监管和联动执法，完善监管信息共享、违法线索互联、案件通报移送等制度，依法严格查处水土保持违法违规行为。同时，深入开展以案释法、以案示警，提高全社会水土保持法治意识。

## 4.5 持续抓好基础支撑能力建设

加强国家水土保持监测站网运行管理，推进省级监测站点优化升级，推动三峡库区、丹江口库区等重点区域监测站点优化组网。深化水土流失动态监测评价，全面推进水土流失图斑落地，实现精准化管理。加强长江流域水土保持数据资源建设，构建水土保持数字化场景，加快监测技术、自动解译和信息化等关键技术应用，推动现代信息技术与水土保持监测深度融合。充分发挥科研院所等多方力量作用，加强水土保持基础研究和关键技术攻关。同时，加大宣传教育和文化建设力度，增强全社会水土保持意识，营造共建共治共享的良好氛围。

## 5 结束语

“十五五”时期是基本实现社会主义现代化夯实基础、全面发力的关键时期，长江经济带发展战略实施也进入了第二个10a。站在新的起点，长江流域水土保持工作将继续牢固树立和践行“绿水青山就是金山银山”理念，坚持山水林田湖草沙一体化保护和系统治理，筑牢长江流域生态安全屏障，全面推进流域高质量发展，为中国式现代化建设提供坚实支撑。
