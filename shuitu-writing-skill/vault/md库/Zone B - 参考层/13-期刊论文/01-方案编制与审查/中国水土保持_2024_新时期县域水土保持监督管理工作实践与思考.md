# 新时期县域水土保持监督管理工作实践与思考

公衍华

（沂水县水利工程保障中心，山东沂水276400)

[关键词]水土保持；监督管理；县域；新时期

[摘 要]“十四五”以来，沂水县把深化“放管服”改革作为全面深化水土保持改革的重要任务，以简政放权、放管结合、优化服务为重点，全面提升水土保持监管水平，成效显著。为落实党的二十大精神和新时期生态文明建设的要求，就县域水土保持监督管理工作中存在的问题提出相应的对策。

新时期县域水土保持监督管理工作要以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大精神，认真落实“十六字”治水思路，牢固树立和积极践行“绿水青山就是金山银山”理念，以推动水土保持高质量发展为主题，全面加强水土流失预防保护，依法强化人为水土流失监管，加快构建县域水土保持发展新格局。沂水县位于沂蒙山区腹地，土地面积$2 ~ 4 3 4 . 8 ~ \mathrm { k m } ^ { 2 }$ ,全县以低山丘陵为主，是山东省水土流失最严重的县域之一，其水土流失情况在北方土石山区具有典型代表性。“十四五”以来，沂水县在国家重点生态功能区、全国水土保持生态环境建设示范县的基础上，严格按照习近平生态文明思想和治水重要论述精神，把深化“放管服”改革作为全面深化水土保持改革的重要任务，不断推进水利部、省水利厅关于深化“放管服”改革、全面加强水土保持监管的安排部署，以简政放权、放管结合、优化服务改革为重点，全面提升水土保持监管水平，服务重点建设项目水土保持工作，为全县水利事业的蓬勃发展提供了坚强的改革支撑与保障。

## 1 主要经验与做法

## 1.1 坚持优化审批，实现审批的便利化、标准化

一是进一步优化审批方式。“十四五”以来，按照水利部《关于进一步深化“放管服”改革全面加强水土保持监管的意见》要求，沂水县不断简化复核程序，提升审批效率，将办理时限从过去的10个法定工作日缩减为7个法定工作日内，其中报告表即时办结。县域内占地不足 $5 \ \mathrm { h m } ^ { 2 }$ 且挖填方量不足 $5 \mathrm { ~ \mathscr ~ { ~ H ~ } ~ m ~ } ^ { 3 }$ 的项目实施承诺制管理，即企业递交报告表及专家审查意见后，当场领取承诺制批复，做到承诺制批复即时下发、水保手续当日办结，人民群众切实受益。3a来，共审批生产建设项目水土保持方案207件，完成80个项目的水土保持自主验收报备，并全部及时录入全国水土保持监督管理系统。二是严格推行水土保持区域评估。沂水县现有经济开发区1处，位于滨河项目区。按照水利部、省水利厅要求，沂水县切实加大对经济开发区的水土保持监管力度，针对经济开发区生产建设项目情况，在县滨河项目区实行水土保持区域评估，通过招标投标的方式，由具有相关资质的第三方机构开展水土保持区域评估报告编制工作。报告编制完成后，统一上报市级水利主管部门进行技术评审，确保经济开发区建设项目顺利开展。三是创新审批方式，抓实“一次办好”。在生产建设项目水土保持手续办理过程中，沂水县积极创新审批方式，利用山东省政务服务网或山东省政府网站“一网通办”实现网上办理，后台审核批复后，建设单位在递交纸质材料的同时领取批复文件。在项目审核过程中，利用网络会议的方式，组织专家进行网络评审，建设单位、方案编制单位、专家只需召开远程视频会议审阅电子版材料，便可对项目进行评审，打破了地域限制，打通了“放管服”改革的“最后一公里”。

## 1.2 坚持事中事后监管，实现监管的多样化、科学化

一是督促协调水土保持补偿费收缴。收缴水土保持补偿费是落实水土保持监管措施的重要抓手，在开展水土保持事中事后监管过程中，沂水县严格按照上级要求，扎实做好水土保持补偿费的收缴工作，具体由水利部门牵头协调行政审批部门做好审批工作，将相关数据推送给税务部门.并全程监督，确保建设单位及时缴纳水土保持补偿费用。“十四五”以来，全县累计收缴水土保持补偿费963.25万元。二是积极开展水土保持专项整治行动。将水利部卫星遥感发现的违法违规生产建设项目作为工作核心，紧紧围绕经济社会发展综合考核这个指挥棒，多管齐下，督促生产建设单位及时完善水土保持相关手续，履行水土保持义务。3a来，沂水县先后通过卫星遥感监管认定、查处疑似违法违规生产建设项目139个，均已责令生产建设单位限期办理水土保持方案报批手续，补缴水土保持补偿费，严格落实水土流失防治责任。同时，通过卫星遥感查处行动，在全县范围内扎实开展生产建设项目水士保持专项整治行动，成立了专项整治行动工作领导小组.抽调专业人员组建工作专班，先后认定、整改“未批先建”项目20个、“未批先验”项目22个、未开展监测项目8个、未缴纳水土保持补偿费项目17个，累计收缴水土保持补偿费264.43万元。三是严格水土保持信用监管。按照《生产建设项目水土保持监督管理办法》《山东省生产建设项目水土保持管理暂行办法》等规章制度要求，严格督促生产建设单位落实水土保持“三同时”制度，3a来累计下达水土保持监管通知书170份、水土保持补偿费缴纳通知书35份，催编水土保持方案通知书165份。同时，严格落实水土保持信用监管“两单”制度，向上级部门推送挂牌督办项目2个、重点关注项目1个，报送典型案例2件。此外，针对73个审批承诺制项目，通过后期监管发现部分生产建设单位承诺不实，扰动范围超出防治责任范围，及时函告行政审批部门撤销行政许可7个，责令生产建设单位重新办理水土保持方案审批手续，补缴水土保持补偿费，严格落实水土流失防治责任。

## 1.3 坚持优化政务服务，实现服务的高效化、规范化

一是优化服务，推进信息公开共享。根据水利部信息化建设的要求，对行政审批事项，凡是不涉及生产建设单位秘密的信息，一律在单位门户网站公开，增加工作透明度，保障群众的知情权、参与权和监督权。充分利用信息网络平台，借助水利部水土保持监测中心技术力量和省内高校的人才优势，对全县126个水土保持监测单元进行实地调查，对发现的3个造成较为严重水土流失的生产建设项目，执法人员及时告知项目负责人，并责令其采取相应的水土流失防治措施。二是开展监督检查和自主验收核查第三方服务。面对全县水土保持监管工作量大、监管任务重的实际情况，沂水县采用政府购买服务的方式，通过公开招标投标，委托具有专业资质的第三方机构提供辅助服务，对县级审批的177个生产建设项目进行监督检查，极大提高了监管效能，摸清了底数，为生产建设项目水土保持专项整治行动的开展奠定了坚实基础。后经专家论证，全县生产建设项目水土保持监督检查和自主验收核查第三方服务达到了预期效果。三是出台相关规范制度，确保事前审批和事中事后监管得到有效衔接。为了让“审批一监管”形成合力，切实从根本上管住人为活动造成的水土流失，沂水县进一步规范了生产建设项目(承诺制项目)行政许可撤销程序、水土保持方案变更手续、弃渣场管理制度、水土保持补偿费征收标准及信用监管办法等。如制定出台了《沂水县生产建设项目水土保持事前审批和事中事后监管暂行规定》，实现了日常项目审批有章可循，事中事后监管有规可依，有效避免了水土保持监管的真空地带，取得了明显的效果。

## 2 监督管理中存在的问题

## 2.1 水土流失防治任务仍很艰巨

一是水土流失面积大。根据水利部遥感调查数据，截至2020年，沂水县水土流失面积仍有810.72km²，占县域面积的33.30%,水土流失较严重[1]。二是资金来源渠道单一。目前，沂水县水土流失治理主要依靠水利、农业农村、林业等国家及省市部门的资金支持，县级资金配套困难，水土流失防治任务仍然艰巨。

## 2.2 县域水土保持监管力量不足

一是人员不足。2019年机构改革后，原有的水土保持监管人员一部分分流到综合行政执法部门，一部分分流到行政审批部门，最终造成水土保持监管机构缺编少人，全县水土保持监管工作能力及效率较以前有所下降。二是监管设备落后。随着水土保持图斑精细化管理要求的提高，现有设备难以满足“天地一体化”动态监管和突发预警等工作的需要。三是监管力度不够。生产建设项目审批立项涉及的部门较多，在当前“提高项目立项审批效率、简化审批流程”的并联审批形势下，水土保持方案、环评等审批不再作为项目立项的前提条件，这就要求在监督执法中要提高执法的力度和硬度2]。四是社会水土保持意识不强。近些年沂水县虽进行了大量水土保持宣传，但大都集中在城区街道范围内，尚未做到全社会覆盖，尤其是农村地区，群众水土保持意识普遍缺乏，有待加强。

## 2.3 水土保持方案落实不到位

一是部分生产建设单位不重视。部分生产建设单位将批准的水土保持方案置之不理，施工中过于追求经济利益而忽视水土保持效益，导致水土保持方案落实不到位。二是缺乏有效的动态监管手段。在实际工作中，水土保持监督管理机构很难对辖区内所有生产建设项目的水保方案实施情况做到了如指掌，多是根据水利部卫星遥感监管违法违规建设项目清单在进行现场核实时才了解一些情况，缺乏常态化动态监管手段。

## 3 对策

## 3.1 增加多方互通联动，打造联合执法平台

以沂水县提出的“项目为王、企业为尊，发展为先、实干为要”为行动纲领，加强水利、发改、生态环境、农业农村、林业、税务等部门间的沟通协作，积极推动项目立项并联审批，建立全县水土保持“监督一审批一执法”联动机制，形成政府各部门“齐抓共建”的联合执法局面。

## 3.2 强化业务能力培训，建设智慧水保平台

新时期基层水土保持监督管理人员要加强相关法律法规的学习及应用，积极参加由水利部、省水利厅、山东水土保持学会组织的监管、监测等业务培训，提升人员业务能力及综合素养，同时加强与高校及科研院所的技术合作，强化新技术、新材料、新设备、新工艺等技术应用，以适应水土保持新形势的发展要求。要充分利用全国水土保持信息管理系统及生产建设项目水保信息化监管系统，辅以无人机航拍、移动终端系统、卫星遥感技术等高科技手段，加快建设县域智慧水保平台，推进水土保持信息化建设进程，实现对生产建设项目的全过程监控，实时掌握水土流失情况，增强对水土流失危害事件的应急处置能力，全面提高水土保持行业管理效率、能力与水平[3]。

## 3.3 狠抓水保方案落实，加强监督执法力度

一是严把行政审批关。有些水土保持方案编制水平一般，弃渣场、防护措施等设计不合理，严重影响了水土保持方案的落实，因此要加强水土保持方案的审核审批工作，严把质量关。二是加强水保方案实施动态监管。严格落实《沂水县生产建设项目水土保持事前审批和事中事后监管暂行规定》，采用监控、无人机航拍、遥感监测、图斑核查等信息化手段，对全县范围内在建生产建设项目进行动态监管，做好与项目负责人的沟通对接，实时掌控水土保持方案的落实情况，对水土保持方案落实不到位的情况要及时提出整改要求，同时做好全国水土保持信息系统数据资料上传工作。三是加大监督执法力度。水土保持监督执法部门要依据相关法律法规严格执法，充分利用无人机、执法记录仪、录音笔等设备，灵活运用约谈、限期整改、行政处罚等手段，加强对生产建设单位和水土保持设计、监测、监理、验收报告编制等单位的行政监管，对违法违规情节严重的单位和个人，要及时移交司法机关处置[4]。

## 3.4 创新水保宣传形式，增强群众水保意识

定期开展水土保持宣传进党校、进学校、进乡村、进社区、进企业、进项目的“六进”活动，利用“世界水日”“中国水周”“全国法制宣传日”“水土保持法颁布周年纪念日”等活动，多渠道、全方位宣传水土保持，同时加强水土保持宣传形式创新，积极利用水土保持公众号、水土保持公园、水土保持科技示范园区等进行水土保持科普及法制宣传，提高群众的水土保持意识和法制观念，提升社会参与度。
