# 关于表土剥离有关问题的探讨

牛光辉<sup>1</sup>，彭梓淦<sup>2</sup>，谭 晓<sup>1</sup>

( 1． 钦州市水土保持监测分站，广西 钦州 535000;2． 钦州市水利局，广西 钦州 535000)

［关键词］表土剥离;剥离量;表土存放;表土利用;表土流转公司

［摘 要］在介绍我国城镇化和工业化建设过程中科学进行表土剥离 利用的意义和表土剥离量 剥离区域及存放位置等问题的基础上，归纳了表土具有的原地或异地景观绿化 土地复垦 土壤改良和造地等用途，提出了表土剥离总量计算 表土剥离区域选择 表土利用的分配及表土的存放原则，并建议由政府部门引导建立表土流转公司，用法律和经济手段解决表土的保护<sub>、</sub>存放<sub>、</sub>调配和利用问题，以便最大程度地保护表土资源，使表土的综合利用效力得到最大程度发挥<sub>。</sub>

## 1 研究的目的和意义

土壤是万物生长之母，在整个生态系统中起着关键的作用<sub>。</sub> 土壤的形成过程极为缓慢，据研究形成 1cm 厚的土壤大约需要 300 ～400 年，在我国西南岩溶区则需要上千年的时间，土壤一旦遭到破坏即很难恢复<sup>［1］</sup><sub>。</sub> 表土是指在土壤剖面中最靠近地表<sub>、</sub>有机质和微生物含量最多<sub>、</sub>对地力快速恢复和植物生长最有利的表层土壤，它是一种稀缺的 不可再生的 具有重要生态价值的基础性资源<sub>。</sub> 目前在我国城镇化和工业化建设过程中，由于对表土资源的重要性认识不够，导致表土资源破坏十分严重，对表土的再利用率也较低，严重影响着我国的耕地安全<sub>、</sub>粮食安全和生态安全<sub>。</sub> 因此，为了保护稀缺的表土资源，在各种生产建设中项目必须科学地进行表土剥离<sub>。</sub> 表土剥离牵涉到 <sup>“</sup>剥离多少<sub>、</sub>剥离多厚<sub>、</sub>存放在哪里和如何利用<sup>”</sup>等一系列问题，理想的做法是 <sup>“</sup>有多少就剥离多少 有多厚就剥离多厚 哪里适合存放就存放在哪里 哪里最需要就用在哪里<sup>”</sup> 但在实际建设中，由于受各种因素的限制无法这样操作，导致各种表土剥离的观点层出不穷，谁对谁错难以分辨<sub>。</sub> 因此，本研究通过对表土剥离若干问题的探讨，试图找出一个较为科学的表土剥离与利用方法，以引起社会各界对表土剥离 利用的重视

## 2 表土剥离存在的问题

## 2． 1 表土剥离的用途问题

目前，表土剥离主要用于建设项目自身的绿化或复垦，称之为原地利用，这对于可剥离表土量较少且自身能够把表土全部利用的建设项目是合适的<sub>。</sub> 但是，对于可剥离表土量较大的建设项目，剥离表土除原地利用外，还会剩余大量的可剥离表土，在这种情况下，多出的表土可以考虑调运给其他需要表土的区域，称之为异地利用<sub>。</sub>

表土的异地利用主要有 3 个方面: 一是用于其他项目的景观绿化和复垦;二是用于低劣耕地的改良，通过对低劣耕地覆土提高耕地质量，变低劣耕地为优质农田;三是造地，通过对不适宜农田耕作或植树造林的区域进行覆土，新造耕地或林地<sup>［2］</sup><sub>。</sub>

另外，对于表土剥离的用途也应该有优先级的安排，应遵循 <sup>“</sup>先原后异<sub>、</sub>先高后低<sup>”</sup>的分配原则<sub>。</sub> 先原后异是表土利用的初次分配，指剥离表土应先满足原地利用，然后再考虑异地利用;先高后低是表土利用的进一步分配，指完成表土的初次分配后，再按照表土利用产生综合效益的大小进行优先级的分配，产生的综合效益越高就越优先分配<sub>。</sub>

例如，一个建设项目的表土剥离量为 1． 0 万 m<sup>3</sup>，若原地只复垦为耕地<sub>、</sub>林地<sub>、</sub>草地中的一种地类，复垦为耕地<sub>、</sub>林地和草地的需土量分别为 0．8 万<sub>、</sub>0．6 万和0．4 万 m<sup>3</sup>，又知复垦耕地产生的综合效益大于林地，复垦林地产生的综合效益又大于草地，则剥离表土就应先满足原地复垦成耕地0．8 万 m<sup>3</sup> 的用土需要，剩余的0．2 万 m<sup>3</sup> 才考虑供给异地利用，在异地利用中也应优先供给能产生最大综合效益的用土需求

综上所述可知，表土剥离可用于原地或异地的景观绿化<sub>、</sub>土地复垦<sub>、</sub>土壤改良和造地等，其利用应先满足原地利用能产生最大综合效益的用土需求，然后再考虑异地利用能产生最大综合效益的用土需求<sub>。</sub>

## 2． 2 表土剥离的总量问题

目前对于表土剥离量的计算有两种观点<sub>。</sub> 一种观点是<sup>“</sup>按需求剥离<sup>”</sup>，其原则是需要多少表土就剥离多少，表土不够时就剥离非表层土补充，既不多剥也不少剥 这种剥离是 <sup>“</sup>先以方向定需求，再以需求找供给<sup>”</sup>，具体做法是先确定好土地的利用方向，据此推算出需土量，然后再根据需土量来剥离表土<sub>。</sub> 剥离表土可分为3 种情况: 一是当表土供给能满足需求时，只剥离表层土，也就是剥离耕地的耕作层或园地 林地 草地的腐殖质层;二是当表土供给不能满足需求时，不仅要剥离表层土，而且要剥离非表层土来补充; 三是若通过补充非表层土的土量还不能满足需求时，就要调整土地的利用方向，以减少表土的需求量<sup>［3］</sup><sub>。</sub> 例如，同一条件下耕地对土壤的需求量肯定比林地多，林地对土壤的需求量肯定比草地多，当不能复垦成耕地时就复垦成林地，不能复垦成林地时再复垦成草地

另一种观点是<sup>“</sup>按供给剥离<sup>”</sup>，其原则是有多少表土就剥离多少，表土有多厚就剥离多厚，只剥离表层土而不剥离非表土层 这种剥离是<sup>“</sup>先以供给定方向，再以方向算需求<sup>”</sup>，具体做法是先分析表土的可供给量，根据可供给量确定土地的利用方向，然后再以土地利用方向计算其需土量 剥离可分两种情况: 一是当表土需求量等于供给量时，表土全部用于建设项目自身;二是当表土需求量小于供给量时，表土除用于建设项目自身外，多出的表土也可以用于异地其他建设项目<sub>。</sub>

按需剥离的优点是当供给表土达不到高一级土地利用方向的覆土厚度时，可用非表土补充，因此可以提高土地利用方向的级别，增加耕地的面积<sub>。</sub> 其缺点是只考虑建设项目内部的用土需求，在没有外部需土的情况下是合适的，若项目可供剥离的表土量较多而外部又有表土需求时，就不能充分利用稀缺的表土资源，造成表土的浪费<sub>。</sub>

按供剥离的优点是可以最大程度地保护稀缺的表土资源，是一种比较理想的剥离方式<sub>。</sub> 但这种剥离存在两种缺陷: 一是当项目的表土剥离量大于其需求量，外部又没有表土需求时，多出的表土就会浪费掉; 二是当项目的表土剥离量小于其需求量，外部又没有表土供给时，土地利用方向的级别就会较低，本来可以复垦成耕地的，由于土层厚度不够只能降级复垦成林草地<sub>。</sub>

## 2． 3 表土剥离的区域问题

由表1 可知，在项目区表土供给量大于需求量且周边区无表土需求时，按需只剥离部分区域的表土，那么到底应该剥离哪些区域的表土好呢? 在这种情况下，表土剥离的区域选择应遵循 <sup>“</sup>先永后临<sub>、</sub> 先高后低<sup>”</sup>的原则<sub>。</sub> 先永后临是对表土剥离区域的初次选择，指先剥离项目永久占地内的表土，当其表土量无法满足需求时，再剥离临时用地内的表土 因为永久占地对表土的破坏是永久性的 不可恢复的，而临时占地对表土的破坏则是短暂的 大多数是可以恢复的，所以永久占地( 建筑物<sub>、</sub>水库淹没区) 内的表土剥离应优先于临时占地<sup>［4］</sup><sub>。</sub> 先高后低是对表土剥离区域的进一步选择，指完成表土剥离区域的初次选择后，按照表土肥力的高低进行优先级的分配，因为肥力高的土壤能充分供给植物所需要的养分 水分 空气，使植物生长发育良好，所以表土肥力越高的区域就越要优先剥离 一般说来，在相同条件下耕地的表土肥力高于林地，而林地的表土肥力又高于草地<sub>。</sub>

例如，一个项目永久用地和临时用地的可剥离表土总量为3．0 万 $\mathbf { m } ^ { 3 }$ ，各地类可剥离表土量见表2，若表土需求量为 1． 0 万 $\mathrm { m } ^ { 3 }$ ，那就只剥离永久用地内的表土，耕地剥离0．8 万 $\mathbf { m } ^ { 3 }$ ，林地剥离0．2 万 $\mathbf { m } ^ { 3 }$ ;若表土需求量为2．4 万 $\mathrm { m } ^ { 3 }$ ，那就既要剥离永久用地内的全部表土 2． 0 万 $\mathrm { m } ^ { 3 }$ ，也要剥离临时用地内耕地的 0． 4 万 $\mathbf { m } ^ { 3 }$ 表土<sub>。</sub>

## 2． 4 表土剥离的存放问题

表土剥离后一般都不会立即被利用，需要先堆放起来 对于表土剥离的存放位置，应遵循 <sup>“</sup>先内后外<sup>”</sup>的原则，即在不影响主体工程建设的情况下，剥离表土存放的位置应优先选择在项目占地的内部，这样能减少地表扰动和植被的损坏范围，符合水土保持法的相关规定<sub>。</sub> 在项目占地内部无法存放的情况下，再考虑在项目用地外堆放表土

对某些建设项目来说，若用地范围内无空闲区域堆放表土，在项目外部堆放表土又因为所在区域征地困难需要承受的经济成本和时间成本太高，在这种情况下剥离表土的存放就比较困难，最终会导致业主不剥离表土或者剥离后乱堆滥放<sub>。</sub> 另外，由于目前许多项目的建设周期较长，表土需要堆放到建设后期才能利用，堆放的表土经过多年的风吹雨淋，既影响环境又造成表土流失 针对这些情况，建议地方政府引导企业成立表土流转公司，运用市场化运作来解决表土剥离的存放和利用问题<sub>。</sub> 例如，对于剥离表土无处堆放<sub>、</sub>无处利用和堆放时间太长的建设项目，可以把剥离的表土卖给表土流转公司，由流转公司负责表土的存储与调配，在需要表土的时候再向表土流转公司购买，这样就能基本实现 <sup>“</sup>即剥即用 即用即有<sup>”</sup>的理想状态，做到剥离表土有固定地点存放<sub>、</sub>多出表土有规划场地利用，最大程度地保护表土资源，既改善了生态环境又减少了表土流失<sub>。</sub>

## 3 结 语

为了达到表土剥离的理想状态，可以考虑通过建立表土的流转机制，用法律和经济手段来解决表土的保护 存放 调配和利用问题，这需要政府 企业和表土流转公司的共同努力来完成 政府需要做的是健全保护表土的法律法规 监管企业执行表土剥离制度 引导建立表土流转公司以及向流转公司购买表土用于土壤改良和造地;企业需要做的是贯彻好表土剥离制度，把多余表土或无处堆放的表土卖给流转公司或向其购买表土用于绿化或复垦; 表土流转公司先购买企业的表土，然后再根据政府和企业的需要，负责表土的科学调配 建立健全表土流转机制，既保护了表土资源，提高了表土的综合利用效益，又调动了业主开展表土剥离的积极性，可实现多方共赢<sub>。</sub>

# 乌审旗水土保持严把项目实施 <sup>“</sup>五关<sup>”</sup>

近年来，乌审旗水土保持工作坚持项目支撑<sub>、</sub>质量优良<sub>、</sub>严格管理<sub>、</sub>惠民实用的原则，始终严把项目实施的<sup>“</sup>五关<sup>”</sup>，保证了重大水土保持项目的成功实施<sub>。</sub>

(1) 项目设计关 对于有意向的水土保持项目，在 《乌审旗无定河流域水土保持规划》总体框架内，以项目建议书的完成为前提，根据 《水土保持工程建设管理办法》，聘请具有乙级资质的设计部门编制项目实施方案<sub>、</sub>项目可行性研究报告<sub>、</sub>项目初步设计，从项目源头把好关<sub>。</sub>

(2) 项目质量监控关<sub>。</sub> 项目进入实施阶段后，严格把好施工质量关<sub>。</sub> 首先对参与技术人员实行 <sup>“</sup>四定一奖罚<sup>”</sup>制度，即: 根据获批的项目，固定全程技术负责人;指定流域治理地块; 核定年度完成治理目标任务;审定经费指标;每年考核，进行奖罚兑现 其次，严格执行基本建设项目 <sup>“</sup>四制<sup>”</sup><sub>。</sub>

(4) 项目档案管理关<sub>。</sub> 按照 《科学技术档案案卷的一般要求》，把依据性材料<sub>、</sub>基础性材料<sub>、</sub>设计性材料 施工性材料 监理性材料 管理性文件材料 竣工验收材料等方面的声像<sub>、</sub>图表<sub>、</sub>文字整理规范<sub>、</sub>完备<sub>、</sub>齐全后归档<sub>。</sub>
