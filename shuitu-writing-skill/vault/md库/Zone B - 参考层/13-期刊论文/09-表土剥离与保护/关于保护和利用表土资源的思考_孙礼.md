# 关于保护和利用表土资源的思考

孙礼

(江西省水利厅，江西南昌330009)

[关键词]水土保持；表土资源；保护；利用

「摘要]水土资源是人类赖以生存的宝贵资源，其中表土资源尤为珍贵。简述了表土资源的价值、流失现状和成因，从认识、立法、规划、技术、操作5个方面分析了保护和利用表土资源的困难，并提出了保护和利用表土资源的建议。

## 1 表土的价值

表土的价值最易被人理解又最易被人忽略。下面是有关资料对表土价值的表述：

据研究，形成1 $\mathbf { c m }$ 厚的表土需要 $1 0 0 { \sim } 4 0 0 \ \mathrm { a } _ { \mathrm { ~ } }$ 农业专家认为，在农田中，形成2.5cm厚的表土一般需要 $2 0 0 { \sim } 1 ~ 0 0 0 ~ \mathrm { a } \mathrm { \Omega }$ 在林地或牧场，形成同等厚度的表土所需时间会更长。

康奈尔大学教授皮门特尔等人在美国《科学》周刊上撰文写到，1 $\mathrm { h m } ^ { 2 }$ 优质土壤含有1000 $\mathbf { k g }$ 蚯蚓、 $1 5 0 ~ \mathrm { k g } ,$ 原生动物、150$\mathbf { k g } ^ { \mathbf { \sigma } }$ 水藻、 $1 \ 7 0 0 \ \mathbf { k g } ^ { 2 }$ 细菌和 $2 7 \ \mathrm { k g } \cdot$ 真菌，所有这些东西都对植物所需的营养要素起着再循环作用，并能提供空气和水赖以流通的通道。表土的表层或接近表层的层面上通常还有腐烂的树叶和植物的根茎，对动物粪便有分解作用。土质好的表土， $1 \ \mathrm { h m } ^ { 2 }$ 包含100t有利于植物生长的各种物质，它们有效地结合在一起将能提供农作物所需95%的氮和25%～50%的磷。表土土层厚度每下降 2.8cm，作物产量就会下降7%。

据分析，表土层的厚度平均 20 cm，厚的可达 30 cm，主要用于农业生产；心土层位于表土层与底土层之间，在表土层以下至50cm深度的范围，结构一般较差，养分含量较低，厚度为20$\sim 3 0 ~ \mathrm { { c m } } ,$ 对于农业来讲，其价值远低于表土；底土层也叫母质层，在心土层以下，是土壤中不受耕作影响、保持母质特点的一层，位于土体表面 $5 0 \sim 6 0 ~ \mathrm { c m }$ 以下的深度，一般称为生土或死土，作为农业生产资源，其价值低于心土。

农民用“一碗土，一碗粮”形象地评价耕作表土。土地资源总量多、人均占有量少、优质耕地少、耕地后备资源少是我国土地的基本国情。我国人均占有土地面积 $0 . 7 7 ~ \mathrm { { h m } ^ { 2 } }$ 只有世界人均量的29%；2003年我国的耕地面积下降到1.234亿 $\mathrm { h m } ^ { 2 } .$ 已接近生存的红线。因此，保护表土意义重大，刻不容缓。

## 2 表土的流失现状与成因

## 2.1 现状

我国是世界上水土流失最严重的国家之一。目前我国约有1/3的耕地受到水土流失的危害，每年流失土壤总量达50亿

t相当于在全国的耕地上刮去1cm厚的地表土；仅黄土高原每年因水土流失带走的氮、磷、钾就达4000万t相当于全国每年生产的化肥总量；被侵蚀掉的土壤的肥沃程度，一般是留下土壤的1.3～5倍。表土流失直接导致土地荒漠化，全国沙漠化土地面积平均每年增加 $1 \ 0 0 0 \mathcal { Z } \ \mathrm { k m } ^ { 2 }$ 。近50年来，我国因水土流失毁掉的耕地达300多万 ${ \mathrm { h m } } ^ { 2 } ,$ 平均每年6万多 ${ \mathrm { h m } } ^ { 2 } ;$ 有0.2亿多 $\mathrm { { h m } ^ { 2 } }$ 耕地遭水土流失侵害，导致耕作层变薄，土地生产力不断下降；因土壤侵蚀造成的退化、沙化、碱化草地面积占我国草地总面积的50%，并且还在以每年0.5%的速度递增。水土流失造成表土丧失(侵蚀严重的坡耕地年均流失土壤达0.6～1.5cm)、地力减退、粮食产量下降，甚至母质、基岩裸露，丧失农业利用价值。生态脆弱、土地紧张的贵州省每年流失表土达1.95亿甘肃每年因水力而产生的土壤侵蚀总量为6.44亿t相当于每年将66.7万 ${ \mathrm { h m } } ^ { 2 }$ 土地刮去表土6.9 cm，土壤流失的速度是成土速度的5～10倍。

## 2.2 成因

(1)自然因素。主要有两个方面：一是我国山区、丘陵区、塬区面积占国土面积的2/3,而这些区域基本都是严重的表土侵蚀区；二是我国大部分地区属于季风气候，降水集中，雨季降水量达年降水总量的60%～80%，且多暴雨，加剧了表土的流失。

(2)社会因素。①我国人口多，粮食和燃料需求很大。在丘陵山区，土地比较紧张，陡坡开垦大量存在，形成了大面积的坡耕地；全国坡耕地达0.213亿 ${ \mathrm { h m } } ^ { 2 } .$ 占耕地总面积的17.5%，而其产生的土壤流失量却达15亿t占全国水土流失总量的1/3。②目前，工业化、城市化带来的大规模资源开采和基础设施建设不仅加剧了对土地的需求，同时也加大了对土壤和植被的破坏力度。据称，全国各项生产和建设活动平均每年搬动和运转的土石方量达到382亿t占全世界总搬运量的28%，不仅使开发建设和生产过程中的表土流失空前加快，而且使大量表土被直接填筑、抛弃或掩埋。③水土流失严重地区多为经济贫困地区，在土壤流失大于土壤形成的区域，若不采取措施对表土资源加以保护，则最终的结果会是土光、水枯、草尽、人穷。

## 3 表土保护和利用的难点

## 3.1 认识方面

土、水、气等许多环境要素的价值都曾一度被轻视或从不计量。当社会普遍感到水的危机时，才开始重视对水资源的保护；社会也同样感到土地的紧张，土地价格开始高涨，目前土地补偿价达到每公顷9万～24万元，但那只是“面积、地盘”的价值，并非土壤的价值，土地危机意识并未转化到土壤危机意识上来，社会对土的珍惜远远不如对水的珍惜，开发建设项目对土壤的取弃几乎到了“滥”的程度。

## 3.2 法律方面

《中华人民共和国土地管理法》规定：县级以上地方人民政府可以要求占用耕地的单位将所占用耕地耕作层的土壤用于新开垦耕地、劣质地或者其他耕地的土壤改良；各级人民政府应当采取措施，维护排灌工程设施，改良土壤，提高地力，防止土地荒漠化、盐渍化、水土流失和污染土地。土地管理法律虽有专门的表层土壤保护、改良和利用条款，但关注的重点在耕地上。水土保持法律法规的立法宗旨是保护和合理利用水土资源，虽然强化了对所有土壤的保护，但侧重对土壤“危害”的治理，没有对土壤保护和利用尤其是表土保护和利用做出明确规定。

## 3.3 规划方面

《全国土地利用总体规划纲要(2006—2020年)》强调严格保护耕地，实行耕地“占补平衡”原则，要求加强恢复工矿废弃地生态功能，加强退化土地治理，但是强调保护耕地并不完全等同于保护土壤。水土保持方案作为一个建设项目保护和合理开发利用水土资源、保护生态的方案，一直把对土壤的取弃和危害治理作为重点，但未将表土作为一种特别宝贵的资源从土壤中分离出来，未能全面考虑土壤具有“资源和危害”的两重性，未能算清土壤价值的经济效益账，只是单纯地认可剥离、运输、存放土壤的成本，即没有将项目造成的土壤流失、浪费、污染、淤塞及其治理等所带来的“损”与取、弃、填土方便所带来的“益”做清楚比较。

## 3.4 技术方面

目前，我们在科学保护、改良和利用土壤方面取得了一定的研究成果，在水土整治方面也制定了水土流失治理的国标、行标和地方标准，但是就如何定量分析开发建设项目对土壤尤其是表土的破坏程度、如何通过管理保护土壤、如何从土壤中分离表土等，却并未系统研究，有的甚至是空白。地区资源承载力、土壤污染容忍力和生态调节力还未实际应用于开发建设项目水土流失防治，土壤尤其是表土保护和利用还亟待出台基础的、客观的、可操作的技术规范作为支撑。

## 3.5 操作方面

耕地的表土保护相对容易，而在地形地貌复杂的区域，保护林地、山地乃至荒地的表土却存在很多困难，几乎没有开发建设项目尝试过，主要原因有3个方面：一是计算有价值表土的深度、面积和方量困难，要像勘测地质一样勘测表土；二是表土的临时存放和保护需要付出一定的经济代价，需要考虑技术可行性和投资；三是表土的利用要考虑综合性、科学性，受自然

和社会条件制约。

## 4 表土保护和利用的探讨

## 4.1 水土保持管理对策探讨

孙鸿烈院士指出，在所有的开发建设项目中，农林开发项目、公路铁路项目、城镇建设项目引起的水土流失最为严重，其中又以农林开发项目造成的水土流失量最大。姜德文博士指出，公路、铁路、露天矿、水利工程等项目消耗和占用土地面积大，对区域土地资源影响大，土石方挖填量、弃渣量远远高于其他项目，对地表的扰动强度大。对地表扰动强度最大的项目当属农林开发，对耕地占用比例最大的当属城镇建设(工业园区、城市新区、房地产)，土石方挖填量、弃渣量最大的当属公路、铁路、露天矿和水利工程建设。地表扰动、占用耕地、土石方挖填弃等是破坏表土最剧烈、最典型的3种形式，是加强表土保护和利用的重点管理内容。

城镇建设项目一般在城区或城郊，无法避免对耕地的占用，而且大多要平整土地，会严重改变原地形地貌和水系。对此，应当实行严格的表土保护政策，要将“耕地占补平衡”作为开发者的法定义务，要求将开发建设与土地再造结合起来，表土要全部收集，专项用于土地再造，尽可能弥补耕地损失；在立法上采取禁止性规范严防表土的浪费和污染，实行最低绿化指标。这样做不仅必要而且可行，这类项目的开发业主一般是当地政府或其设立的管理机构，具有很高的权威和协调管理能力，完全可以通过合同的、行政的、经济的手段将表土全部用于附近农村造地，实现城乡双赢。

农林开发项目是直接利用表土资源的项目，但是近些年来，由于过度规模和连片开发，造成了剧烈的表土流失。在许多地区，这种项目区成了表土流失的最大源地。对此，一些地方政府制定了农林开发“三三制”，即在一定区域内，1/3开发、1/3保护、1/3种植生态林；有的实行严格的“开发禁区”政策，即划定生态保护区、水源区、江河湖库迎水面山坡等为严禁开发区；还有的地方提出水土保持先规划、农林开发后实施，在保护中开发，在开发中保护。这些做法的深刻启示是：大规模的农林开发多由政府号召和推动、农林企业或农户具体实施，只有政府能够统一管理、统一要求；基层政府制定的土壤保护政策，最有效也最具针对性、地方性和操作性；在不能科学、准确确定生态保护模式的前提下，及时提出一个保守而不激进的生态保护模式，实行保护优先政策具有积极意义；健全禁止、限制和鼓励性政策，引导农林开发治理，即禁止重型机械开发，禁止全垦、炼山垦、顺坡垦，限制开发规模、连片面积，限制大面积灭草、复垦，鼓励保土耕作、退耕还林还草、免耕等先进的生产方式，实行经济补偿，引导农户实施治理措施。

公路、铁路和矿山等开发建设项目保护表土的操作较为复杂。首先，需要将表土作为要素之一进行分区。其次，需要按分区对其表土分别作出处理。对无法避免大面积占用耕地和水田的，则实行严格保护表土的政策，责令建设单位履行耕地再造义务，促使项目业主自觉避免使用耕地；对于林地，则根据实际情况剥离和收集表土，用于工程绿化；对于取弃土场，则采取表土、心土分离措施，分别用于回填和填筑，要求开挖面与地面取平，不留深坑、陡坡，为造地或回填绿化创造有利条件；提倡整个项目土石方平衡，综合利用土壤，做到“零抛弃”。水利工程取土量大、集中，对土质要求高，可实行严格的表土保护和利用政策，强化耕地再造义务。

## 4.2 水土保持方案对策探讨

上述管理设想可通过水土保持方案系统地、具体地来实现。

## 4.2.1 关于土壤

在水土保持方案自然概况一章中，有项目区土壤类型、土层厚度、土壤质地和抗蚀性一般要求等内容。若考虑表土，建议着重介绍土壤的分布、结构、肥力和不同层面土壤的最佳用途，然后分别就不同占地类型，分析表土的性质、价值、数量，为后续土壤特别是表土的保护和利用提供客观和基础依据，加强自然概况与后续设计和措施的有机联系。

## 4.2.2 关于土石方平衡

在土石方平衡一章中，建议着重考虑挖填土壤的区(段)平衡和整体项目的平衡，在计入土壤价值的前提下，权衡土石方平衡的经济技术可行性。严格将表土从土壤中分离出来，综合考虑利用途径和方式。现在方案对灰渣的利用开始重视，而对表土的利用也可以这样考虑。

## 4.2.3 关于主体工程水土保持分析与评价

这里的主体工程应当指整个项目工程，而不宜理解为项目中具有水土保持功能的主体工程。而凡涉及可能造成水土流失项目的水土保持分析评价，首先要对占用和破坏表土进行分析评价。对表土的占用和破坏是项目对生态负面影响的必然结果，究其原因，表土是水土保持首要关心的问题，弃此而仅关注对防洪、水系、工程的分析评价是不合适的，开发建设项目对表土的破坏和占用一般是以占压和毁弃土地、取弃土壤的形式表现的，如果运用开发建设项目水土保持损益分析方法，不仅可以定性分析项目建设给生态带来的负面影响，而且可以定量计算。

## 4.2.4 关于保护和利用表土的设计

过去方案大多会提到一些表土的问题，现在已有专门的章节。这个章节一般要涉及表土的剥离、保护和利用3个主要环节。

(1)表土的剥离。所谓表土剥离，即在土地开发利用中，将土地表层5～50cm厚的土壤，在开发建设项目用地前先行剥离出来，保存或运至事先设置的区域。表土剥离考虑的要素是分区分地类、剥离的工艺和时期、取土厚度(视利用价值决定)和方量，以及运输的方式等，由此设计出最佳方案。

(2)表土的存放。方案应对表土的收集，保存的地点、方式、时间及防护措施等作出计划。所收集表土应为富含有机质的表层土壤，保水、保肥、通气、透水，且不含垃圾杂物、硬黏土块或直径大于5cm之砾石。因此，在剥离前应进行清除及掘除工作，先移除地表植物及树根，再挖松表层土壤，清除杂物、石粒后收集装运至堆置场所存放。自用时，存放表土的地点一般在工地临时设置；堆土的保护要避免破坏表土特性，机械操作时应避免过度辗压；堆置场防护要采取排水、拦挡、覆盖等临时防护措施；工矿长期堆置的表土还应采取永久工程措施和表层

覆盖、植草等稳定土面的措施。

(3)表土的综合利用。一是要明确表土的利用途径。分异用和自用两种，占用耕地的表土最好异用造地，实现土地面积和地力的“占补平衡”；占用林地的表土，则多为自用。不同的项目对表土的利用不同，长期项目如矿山表土剥离量大、集中，且存放时间长，要考虑矿山废弃后的整地恢复，因此存放点和治理是重点；中期项目如公路、铁路的坡面、路肩和取弃土场的绿化任务很重，需要大量的表土，且利用期限确定，一般要在竣工前使用完。许多绿化工程收不到预期效果，原因之一就是没有自用好表土，即不是在表土上植树种草，而是在母质土或心层土上种植草木，这样的结果往往是林草成活率低、生长慢。二是要明确利用技术。路堤或整地竣工植草前，应先清除地面残留的砾石、混凝土块或其他垃圾杂物，再回填表土，表土回填时亦可混合基肥或土壤改良剂以利植草；应均匀回填表土并夯压整平，表土复原地的地基应耕起一定的厚度，以便和复原表土合为一体。一般绿化回填整平后，表土厚度不小于5cm(植树和种草要求的厚度不同)，并应尽快植草以防表土流失。土壤硬度适当以保证根系充分伸长和维持良好的通气性和透水性，避免土壤板结，确保排水性和透水性。三是选好利用时间。要避免在干旱或暴雨季节回填表土，以提高利用效率。

# 安远开展新一轮稀土矿区水土流失整治工作

为了遏制稀土矿区严重的水土流失，改善矿区生态环境，确保矿区周边和下游群众生产生活安全，安远县水保部门高度重视稀土矿区的水土保持工作，2009年12月至2010年3月，对全县57个稀土矿点展开了新一轮水土流失整治工作。

(1)成立了以局长为组长，分管副局长为副组长，有关股、室负责人为成员的稀土矿区整治领导小组，并成立了由分管副局长为组长的整治工作组。

(2)制定了切实可行的整治工作方案，规定了整治工作时间、方法和步骤，明确了工作组的具体职责。

(3)认真开展调查摸底工作。通过逐一排查，发现57个稀土矿点都存在不同程度的水土流失现象，并存在一定的安全隐患。植被恢复较好的只有5个矿点，所有矿点尾砂坝、挡土墙和截流沟均存在不同程度的破损现象，其中有7个矿点存在较严重的安全隐患。

(4)制定了严格的整治方案和措施。到2010年3月底止，必须完成以下整治工作任务：一是植被恢复面积627.3 hm2；二是加固和新增浆砌块石尾砂坝47座；三是浆砌截流沟18.75 km;四是浆砌挡土墙10.43 km，计划总投资1243万元。
