## 1 前 言

加强城市水土保持工作，以保障城市化平衡有序的进行是十分必要的。沉沙池设计是开发区场平水土保持工程重要的措施之一，而沉沙池的设计从理论至实践都是值得探讨的课题。

为集中讨论，本文的沉沙池设计主要考虑城市化开发的住宅区、别墅区、工业园区或片区整片土地开发的场平工程施工中的沉沙池设计的方法问题。闲置开发区水土流失治理的沉沙池设计也适用于本方法。

## 2 沉沙池设计中应考虑的有关因素分析

## 2.1 设置沉沙池的必要条件

严格来讲，任何城区的建筑工地在径流集中排出口都应设置沉沙池，以减少下游排水沟或下水道的泥沙淤积。为了集中清淤，在上游流域侵蚀较严重的小流域沟道整治的适当河床位置也经常要求设置沉沙池。就开发区而言，我们在水土保持方案编报实践中，总结出在如下的情况下可能产生较严重的水土流失，必须在施工期设置临时沉沙池：(1)红线边界范围在设计中具有大于2m高差的填土边坡或大于7.5m 高差的开挖边坡；(2)红线范围内地形主纵坡的坡度大于5(GB分级为中度以上侵蚀强度的低限，侵蚀模数 $\begin{array} { r } { M _ { s } > 1 ~ 5 0 0 ~ \mathrm { { t } / ( ~ k m ^ { 2 } ~ \cdot ~ } } \end{array}$ a))；(3)有集水区水沟穿过地块或从项目区红线边界经过。

## 2.2 设计标准

根据城市社会经济综合分析，按照城市防洪的要求，在深圳市开发平土区场平水土保持方案设计实践中，对涉及山洪径流的截流沟，按50年一遇暴雨频率标准设计；对场区内的临时排水设施，采用10年一遇暴雨频率标准。在沉沙池设计标准中，还没有一个较为公认的标准。由于开发区场平工程一般只经过一个雨季施工期，正常情况下，大面积场平工程一般也在2年左右。从技术经济分析的角度，我们在实际的设计实践中，沉沙池的沉沙设计参数采用5年一遇或均值暴雨量标准，而过流能力校核仍按10年一遇暴雨标准。根据深圳地区不同暴雨标准的1h最大暴雨量及流量的差异分析可知，5年一遇和20年一遇的流量分别比均值流量大32%和90%。

根据《深圳市水土保持生态环境建设规划》(2000)，城市开发建设在施工期的侵蚀模数应控制在500t/$\mathrm { ( ~ k m } ^ { \mathrm { ~ 2 ~ } } \mathrm { \bullet } )$ 以下。

## 2.3沉沙池的类型、布置与有关考虑

沉沙池可分为永久性沉沙池和临时性沉沙池。施工中的沉沙池常为临时性，即施工完成后，集雨控制范围全部实施软硬覆盖和边坡防护，沉沙池的使命即已完成，则沉沙池回填绿化或改作它用，如改为喷水池、观赏水塘等。永久性沉沙池一般设置在永久性排水沟的汇流处或涵管入口处。

临时性沉沙池可就地开挖而不护砌或简单护砌；条件许可时，还可以利用天然低洼地形，适当建拦沙坝，形成沉沙池。

永久性沉沙池一般采用浆砌石护砌并用砂浆抹面。为清淤方便，对大型沉沙池，应考虑设置挖掘机械进出池的引道；对小型沉沙池，便于人工清淤，一般池深控制在1.5m左右。

依地形而形成的临时沉沙池，形状一般不规则，计算时可按相当的箱型尺寸进行校核。人工沉沙池一般采用箱型，长宽比 $( L / B )$ 一般可取1.5～3.5.池入口段应设置扩散段，以利于水流均匀扩散，增加泥沙沉淀效率。永久性沉沙池一般来沙模数较小，计算沉积容量时可按1年一次 $( n ^ { \mathrm { ~ = ~ } 1 } )$ 进行清淤。施工期临时沉沙池清淤可根据情况1年一次或数次，甚至要求每场大暴雨前必须清淤，主要根据来沙量大小和施工情况而定。

## 3 泥沙沉淀的动力学原理

在水中的泥沙颗粒受自身重力作用具有下沉的趋势，而水流的紊动对泥沙颗粒具有顶托作用，因此，水流具有一定的挟沙力，当水流在沉沙池内突然扩散，水流速度大大减小，水流的挟沙力也大大降低，较粗颗粒泥沙就会下沉，这就是沉沙池的沉淀原理。当水流流速趋于0时，挟沙力也趋于 $\mathsf { \Omega } _ { : 0 } [ 3 ]$ 。这时，泥沙可认为是在静水中下沉，泥沙在静水中下沉时，从加速到等速所经历的时间十分短暂。当粒径 $D = 1 _ { \bf m m }$ 时，加速时间不到 $1 / 2 0 \mathrm { s }$ , D愈小，加速下沉的时间愈短。因此，在工程上一般按泥沙颗粒匀速下降处理⁵]。

(4)建议花岗岩风化区的场平工程(或闲置开发区治理工程)沉沙池设计一般采用 $\omega _ { \astrosun } = 0 . 1$ 的设计参数，减沙率按75%计。要进一步提高减沙效率，除采用上游其它拦截或覆盖等措施外，还可设计多级沉沙池系统。

## 4结论

(1)栾树、黄栌、黄连木、刺槐的叶片水势日变化规律基本一致，都为先降低后升高，14:00～16:00左右达到最低值。各树种叶片水势日变化的幅度依次为栾树>刺槐>黄栌>黄连木，这说明黄连木受外界条件变化的影响最小，水分利用效率最高。

(2)栾树、黄栌、黄连木及刺槐的气孔导度日变化均为单峰型，上午8:00～10:00达到高峰。这4个树种的气孔导度为黄栌>刺槐>栾树>黄连木，黄连木的气孔导度最小，说明在相同条件下，其水分利用效率最高。

(3)栾树、黄栌、黄连木及刺槐4个树种的日平均蒸腾速率依次为刺槐>黄栌>栾树>黄连木，这说明黄连木的蒸腾耗水量最小，最抗旱。

(4)栾树、黄栌、黄连木及刺槐的土壤呼吸速率依次为黄连木>栾树>刺槐>黄栌，说明黄连木的土壤透气性最好。
